# 我的专家插件包

私有仓库，收录 4 个 WorkBuddy/DeepSeek Harness 专家插件，供个人项目复用。

---

## 目录结构

```
.
├── ai-video-factory/      # AI 视频工厂：从选题到成片的全自动化流水线
├── gzh-content-ops/       # 公众号内容运营：选题→写稿→排版→发布→复盘闭环
├── taobao-image-team/     # 淘宝图片团队：主图/详情页/白底图标准化生产
└── xhs-content-studio/    # 小红书内容工作室：笔记框架+配图→发布包→数据复盘
```

## 4 个专家包简介

### 1. ai-video-factory
**用途**：给一个选题/文章，产出 9:16 / 1:1 / 3:4 三画幅成片（中文配音 + 逐句字幕 + BGM + 封面 + 发布文案 + 验收帧），全程本机、无需云端 Key。

**核心能力**：
- 14 个专业 Agent 协作（选题策划、脚本分镜、角色设计、动作设计、封面品牌、数据可视化、后期剪辑、发布增长等）
- 支持即梦/Seedream 本地生图、TTS 混音、Remotion 渲染
- 内置合规自检、AI 口味评分、多版本对比

**入口**：`agents/ai-video-factory-team-lead.md`

---

### 2. gzh-content-ops
**用途**：公众号长文全流水线——“薄肌小王翻盘实录”风格。一人干几摊的真实复盘，主线悬念贯穿 + 对上篇立帖对账 + 分节长文 + 21:9/1:1/正文插图三件套 + 去 AI 味 + 推公众号草稿箱。

**核心能力**：
- 7 角色编排：Scout(选题) → Adaptor(改写) → Editor(编辑) → Visual(视觉) → Compliance(合规) → Publisher(发布) → Analyst(复盘)
- 资产库：IP 设定、配色方案、排版模板、风控词库
- Writer App：本地长文写作助手（记忆、人设、大纲、质检）

**入口**：`team/ORCHESTRATOR.md` / `skills/gzh-workflow/SKILL.md`

---

### 3. taobao-image-team
**用途**：淘宝/天猫商品图标准化生产——主图、导购图、白底图、长图详情页，按《淘宝规格 2026》交付。

**核心能力**：
- 订单摄入 → 素材清洗 → 模板填充 → 批量渲染 → 合规自检 → 交付包
- 模板库：白底图 S1、导购图 3×4、长图详情页等
- 定价/入驻/交付 SOP 文档化

**入口**：`skills/taobao-image-workflow/SKILL.md`

---

### 4. xhs-content-studio
**用途**：小红书笔记半自动化工作流——“你写框架 + 你备图” → 一键扩写 → 体检 → 出「发布台.html」→ 手动复制粘贴发布。

**核心能力**：
- 硬规格闸门：标题 ≤20 字、正文 ≤1000 字、配图 1-18 张、站外引流词/买卖措辞 FAIL
- 多账号隔离（薄肌小王 / 旧人设已废）
- 引擎脚本：评论挖掘、发布时间探测、选题挖掘 Pipeline、排版路由
- 状态管理：选题库、需求挖掘报告、方向确认、实测数据回填

**入口**：`engine/挖掘pipeline.md` / `accounts/薄肌小王/`

---

## 使用方式

每个插件包内部自带 `SKILL.md` 或 `ORCHESTRATOR.md`，按其中说明调用对应 Agent/Workflow。

本仓库不含任何自动发布/登录逻辑，所有产出均为本地文件，人工复核后再发布。
