# 发布测量回填模板（G-D 闭环）

> 每篇发布后回填一条，作为选题校准的输入。**无回填 = 开环，系统会漂。**
> 文件名建议：`YYYY-MM-DD_笔记主题.md`

## 回填字段

- 发布日期 / 星期 / 时段（是否踩中 state 推荐的时段）
- 笔记主题与对应选题库条目
- 曝光量（若有）
- 赞 / 藏 / 评 / 涨粉
- 收藏率 = 藏 / 赞（干货型 > 0.3 及格）
- 评论率 = 评 / 赞（> 0.05 及格，低于说明没戳痛点或钩子弱）
- 钩子转化：扣【清单】等引导词条数（衡量引流有效性）
- 前 2 小时互动是否达标
- 复盘结论（哪句钩子有效 / 哪张图被划走 / 标题是否吸睛）
- 下篇调整动作

## 校准规则

- 连续 3 篇收藏率 < 0.2 → 内容不够「可保存」，回炉选题库。
- 钩子转化趋零 → 钩子话术或位置有问题。
- 第 3 周用创作中心「粉丝活跃时间」校准发稿钟点。
