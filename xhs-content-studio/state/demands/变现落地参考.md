## 二、虚拟品评论诉求（80 条评论 → 用户在求什么）

| 诉求 | 条数 | 含义 |
|---|---|---|
| 问选品 / 卖什么 | 5 | **最强信号**：用户最缺"卖什么"的答案 → 选品清单是刚需 |
| 求教程 / 怎么做 | 6 | 要 step-by-step，不要概念 |
| 吐槽 / 焦虑（合规·坑） | 4 | 怕违规、怕被罚 → 合规内容有市场 |
| 求资料 / 模板 | 2 | 要现成可抄的 |
| 求带 / 变现 / 接单 | **0** | 虚拟品用户想**自己干**，不是被收徒 → 别做"收徒带赚"，做"资料/SOP售卖" |

**产品/内容设计结论**：虚拟品方向卖「选品清单 + 上架教程 + 合规避坑」三件套，**不做收徒变现**。这正好和你"小红书虚拟品真需求挖掘（求助词+30天+时令）"的方法论合流。

## 三、引流标题公式库（信息整理 / AI知识管理 56 条高赞提炼）

高频公式词：**搭建(9) > 教程(3) 进阶(2) 打工人(2) 普通人·实战·自动化·案例·背下来·保姆·小白 各1**。

可直接套的 7 类模板：

1. **【清单盘点类】**（收藏率最高）
   - 模板：`20XX最好用的XX工具` / `XX个神仙XX` / `XX工具分类表｜打工人必备`
   - 例证：11000赞"一图看懂｜2026最好用的AI工具"、1293赞"2026AI工具分类表"
2. **【搭建教程类】**（"搭建"最高频）
   - 模板：`随手搭建个人XX` / `用AI+XX搭XX（小白友好）` / `XX搭建全流程（超详细）` / `自生长式XX保姆级教程`
   - 例证：11000赞"知识复利｜随手搭建个人知识库"、281赞"用AI搭建自生长式知识库保姆级教程"
3. **【普通人/打工人人设类】**（降门槛、强共鸣）
   - 模板：`普通人如何XX` / `打工人「穷鬼」XX套餐`
   - 例证：6795赞"普通人如何构建跨AI共享个人档案"、2201赞"打工人穷鬼AI套餐"
4. **【反直觉/争议类】**（反共识吸睛）
   - 模板：`XX就是一坨` / `先别用XX了` / `别再傻学了！这XX个指令闷声用`
   - 例证：1705赞"RAG就是一坨"、349赞"先别用Obsidian建AI知识库了"、309赞"别再傻学了"
5. **【一图看懂类】**（视觉化、低门槛）
   - 模板：`一图看懂｜XX` / `一张图看懂XX的X个概念`
   - 例证：11000赞"一图看懂｜2026最好用的AI工具"、438赞"一张图看懂AI的8个概念"
6. **【背书/结果类】**
   - 模板：`知识复利100%` / `被全球模仿的XX` / `吃透X个案例你的XX就很牛`
   - 例证：1372赞"吃透这15个案例，你的workbuddy就很牛"
7. **【指令/模板类】**（对应评论层141条求模板）
   - 模板：`这X个XX指令闷声用` / `背下来你的XX就很牛` / `用这个prompt就可以`
   - 例证：1317赞"背下来！你的AI Agent就会很牛"、409赞"用这个prompt就可以了"

## 四、钩子设计（复用评论层结论）

- **评论层第一诉求=求模板/资料（141 条）** → 每篇引流笔记正文或置顶评论都放"可下载清单/模板/SOP"领取钩子（如"虚拟品选品清单100个""上架SOP"）。
- 虚拟品账号钩子优先级：选品清单 > 上架教程 > 合规避坑，按 §二 诉求排序给。
- 合规铁律：投研背景只做"效率/情报整理"人设，**不荐股、不谈买卖**，评论区也控。
