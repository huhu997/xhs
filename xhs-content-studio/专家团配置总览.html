5 · 7 道 Gate 全文（引擎规则，brief 简卡来源）

G-A~G-F 是防错型（保证不出事）；G-H 是唯一正向质量闸（保证有人看）。全过 ≠ 好看。

G-A 人设事实核查 11-05 修订

经验陈述须映射到 state/facts.md，否则改记录者 / 研究者视角。修订：只防编造，不等于把第一人称删光——真实资产（挖 300 篇笔记 / 1179 条评论、93 个去重 skill、CDP 抓数、投研背景）每篇至少 1 处，且必须落成具体动作或场景。禁的是「试了两周 / 实测有效 / 卖了多少单」，不是真实做过的动作。

G-B 需求带时间戳

挖掘产出必须标采集日期，pipeline 可重跑，禁止把旧数字当永恒真理；无 API key 时用 state/demands/ 历史报告并标日期，不编实时榜单 / 热搜 / 新数字。

G-C 选题从变现路径派生 11-05 修订

先钉变现路径，选题 / 钩子 / 时段 / 形态全从它派生。修订：① 禁止从高赞标题公式倒推选题；定选题前先答「把谁、往哪一步变现路径推进一步」 ② 每 3 篇至少 1 篇接主变现（虚拟品 / 资料包 / 店铺），不许连续 3 篇「纯分享不卖课 + 站内扣词白送」。

G-D 发布必回填 measurement

每篇发完按 state/measurements/ 模板回填（前 2h 互动 / 钩子转化 / 第 3 天粉丝活跃时间 / CTR），无回填 = 开环。

G-E 只调 verified 能力

只用已验证能力：CDP 抓数脚本 + marketing-card-render（Apple 暖色 A/B/C）+ guizang-card-render（瑞士风）+ proxy-fetch shim。一篇只用一套视觉，不混搭；不为「AI 插画感」碰 baoyu 逆向通道。

G-F 跨篇去雷同 11-05 修订：骨架层

写稿前打开上一篇清单，逐层比：开头痛点 / 数据锚点 / 反直觉结论 / 金句 / 人设自证 / 交付物 / 钩子 / 5 图语义 / 标签。最高优先级＝叙事骨架：各压成一行「谁 → 遇到什么 → 我给了什么 → 怎么互动」，骨架撞即判雷同、单条即触发，不累计。允许保留赛道 / 视觉 / 站内扣词机制，但钩子话术不得换皮。

明确禁用骨架：泛痛点 → 我整理成一份 → 评论区扣【X】领 → 评论区问一句（D1 / D2 v2 / D2B 三篇全中，旧表 13 层却全判 ✅）。

G-H 内容张力（正向质量闸） 11-05 新增

折叠全部自检表，只读正文，出图之前逐条过六问，任一为否不出稿：

① 有没有一句别人写不出来的话（真实资产 / 具体数字 / 具体场景）？
② 开头 3 行有没有具体画面或冲突，而不是「很多人都会……」？
③ 删掉全部 emoji、编号、小标题后，还像人说话吗？
④ 有没有让人想截图 / 转给朋友的具体细节（不是「4 栏」「3 步」这种抽象结构）？
⑤ 钩子是不是上一篇换皮？「纯分享不卖课」是不是又原样出现？
⑥ 发布清单里自检表篇幅是否 > 正文 3 倍（超了判本末倒置，退回）？

触发案例：D2B 清单 213 行 / 正文 18 行，六闸全 ✅，用户仍判「有点糟糕」。
