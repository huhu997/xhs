# 小红书需求挖掘方法论（实战沉淀）

> 来源：WorkBuddy 赛道实测，2026-11-03，21 关键词 / 640+ 笔记 / 34 篇评论深挖 / 444 条评论 / 182 条痛点。
> 工具链：本机登录态 Chrome(9222) + CDP 直采，零 API 成本。

## 一、赛道判断：被验证、未垄断的信号

「workbuddy教程」篇均 3,664 赞，接近全站泛词「教程」的 4,231，而「技能包」只有 148。
**用户不为"包"买单，为"学会"买单。** 头部 12 篇来自 9 个不同账号，无垄断；内容同质化在"零基础/保姆级/1 小时入门"；**进阶实战 + 职业场景是空位**。

## 二、核心规律：越火的帖，提问的人越少

| 分档 | 篇数 | 痛点密度 |
|---|---|---|
| 低赞 <1k | 5 | **54%** |
| 中腰 1k-3k | 8 | 46% |
| 中头 3k-8k | 11 | 43% |
| 爆款 >8k | 6 | **22%** |

**大爆款带来围观和收藏，真正在动手、卡壳、有付费意愿的人在 1k-8k 赞的中腰部。** 矩阵策略：用大爆款抢流量入口，用中腰部内容做转化。

## 三、六个真需求（过滤噪音后）

1. **教师是核心人群**：教资帖 3,470 赞、47% 痛点密度；痛点明确（备课、课件、出卷）。
2. **额度焦虑是最大付费阻碍**：24 条价格/额度痛点，语气最激烈（"额度太少""很快用完要付费"）。
3. **记忆/上下文持续性**：认知断层富矿（"关机再开它还在吗"），市面几无内容。
4. **Skill 效果不及预期**：进阶用户卡在 skill 输出质量控制与衔接（"pptx 把我漂漂亮亮的 HTML 改成纯文本"）。
5. **@点点 刷屏**：AI 资讯订阅是被反复表达的需求（精选、无广告）。
6. **办公自动化具体场景**：报销 OA、教师、科研、跨境。

## 五、标题公式（数据支持）

- ✅「学会」+「保姆级」+ 具体时长 —— 带「学会」篇均 5,355 赞，是带「免费」的 10 倍
- ✅ 场景具体化 ——《教师的 8 个 WorkBuddy skill：备课到出卷全流程》
- ❌ 避免「免费」「合集」「技能包」—— 篇均仅 148-530

## 六、不建议做

- **卖"资源包/技能包合集"**：「技能包」篇均 148 赞，市场已脱敏
- **本地部署/一键部署**：篇均 45-139，受众极窄
- **纯 AI 工具清单**：头部已有 11,000 赞内容，新号难切

## 七、工具链（可复用脚本，在工作区 `小红书需求挖掘/`）

| 脚本 | 用途 |
|---|---|
| `xhs_search.mjs "关键词" 输出.json 8` | 关键词 → 笔记列表 |
| `collect_tokens_cli.mjs "词1" "词2"` | 批量拿带 xsec_token 的笔记链接（评论挖掘必需） |
| `xhs_comments_dom.mjs "URL" 输出.json 10` | 单篇 → 评论区（主评论 + 楼中楼） |
| `aggregate_all.mjs` | 多词聚合 + 跨词爆款榜 + 形态词频 |
| `analyze_comments_all.mjs` | 全量痛点分类 + 点赞分档密度验证 |
| `pain_quotes.mjs` | 过滤 AI 总结噪音，提炼真人原话 |

**已知限制**：PC 网页端笔记页只渲染首屏约 10-19 条高赞评论。首屏恰是高赞评论，痛点信号最密。
