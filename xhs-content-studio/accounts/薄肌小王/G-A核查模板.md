# G-A 人设事实核查模板（每篇写稿前必填 · 不填不出稿）

> 复制本模板到新稿顶部，填完再动笔。这是 Gate A 的硬动作——把"编经历翻车"在动笔前掐死。
> 自查一句：读者追问我真实经历，我答得上吗？答不上 → 那句话改记录者 / 研究者视角。

## 稿名：__________（如 D1 流量入口·信息整理清单）

### 1. 本篇可引用的真实事实（从 `state/facts.md` 摘录，只写做过的）
- [ ] 例：我用脚本挖了 300 篇笔记 + 上千评论（真）
- [ ] 例：我基于这批数据整理出「信息整理四步模板」这份资料（真：资料确实做了）
- [ ] 例：我做投研 + AI 情报系统（真）
- ⚠️ **反例（这组模板早期留过，已删）**："我试了两周，收藏夹终于不堆灰了" —— 用户没试过两周，属编造体验，**禁止出现**。资料做了 ≠ 用过两周。

### 2. 本篇红线（明确没做过的，禁止第一人称写成经验）
- [ ] 例：虚拟品一单未卖 → 不写"我筛了100个、踩过坑、实测能跑"
- [ ] 例：未实盘 → 不写"我买卖了 / 账户赚了多少"
- [ ] 例：未跑通教人赚钱 → 不写"我靠教XX赚了XX"

### 3. 逐句自检（把正文里所有"我…"列出来，逐一标 ✅可引用 / 🚫要改）

| 例："我挖了 300 篇" | ✅ 挖数真做过 | — |
| 例："我用 XX 效率翻 3 倍" | — | 🚫 无数据，删掉，改成客观描述"这套模板分四步：输入→分类→沉淀→复用" |
