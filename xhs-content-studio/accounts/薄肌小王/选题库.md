## 五、发布时段策略（北京时间为准 · 理论推演，第 3 周用创作中心校准）

### 5.1 为什么虚拟品号也看时段
受众吃晚间主峰（20:00–22:00 刷得最勤）；投研背书内容才受交易时段约束（盘前/盘后）。冷启动窗口 = 发后 1–2h，要在高峰前 1.5h 发。

### 5.2 各内容类型最佳时段
| 内容类型 | 最佳时段 | 逻辑 |
|---|---|---|
| 长文方法论 / 清单盘点（首发 3 篇属此类） | 周中晚 **20:00–22:00**；或周六/日上午 **9:30–11:30** | 晚间主峰愿看深度；周末研究人群在线、完读高 |
| 虚拟品选品 / 上架 SOP | 晚间 **20:00–22:00**（吃主峰即可） | 无交易时段约束，吃晚间流量 |
| 投研视角观点（仅背书） | 工作日 **8:30–9:00**（A股盘前）/ **21:00–22:00**（美股盘前·冬令时） | 时效内容，过时废；只讲观点不荐股 |
| 周末深度 / 周复盘 | **周六 9:30–11:30** 或 **周日 21:00–22:00** | 周末时间长，完读收藏最高 |

### 5.3 避开三类坑
- ❌ 工作日上午发长文（被工作/盯盘打断，完读低）。
- ❌ 23:30 后发（主峰已过，冷启动稀薄）。
- ❌ 盘前发长文（盘前只扫快讯，长文被划走）。
- ✅ 长文统一提前到高峰前 1.5h（18:30–19:30 发，吃 20:00 主峰冷启动）。

### 5.4 首周排期（落具体星期 + 钟点）
| 篇 | 星期 | 钟点 | 逻辑 |
|---|---|---|---|
| D1 流量入口 | **周六** | 10:00 | 周末研究人群在线、深度完读高 |
| D3 主变现 | **周二** | 20:30 | 周中晚间主峰 |
| D5 信任背书 | **周四** | 20:30 | 临近周末转化心智强 |

### 5.5 常态周更（第 2 周起）
周二 20:30 方法论 / 清单｜周四 20:30 避坑复盘｜周六 10:00 深度长文 / 周复盘｜（可选）周日 21:00 投研观点。
> 校准：前 2 周按上表，第 3 周用创作中心「粉丝活跃时间」微调钟点。时段是优化项不是决定项。

## 六、合规自查（发布前必过）

### 6.1 小红书违禁 / 限流词
| 风险类 | 典型词 | 本号处理 |
|---|---|---|
| 极限词 | 最 / 第一 / 绝对 / 100% / guaranteed | 改「超 / 挺 / 多数」 |
| 收益夸大 | 躺赚 / 月入X万 / 稳赚 / 轻松赚 | **严禁**，只讲真实踩坑+真实数据 |
| 导流词 | 私聊 / 加微信 / 移步某宝某音 | 不用，成交走平台内，不引导站外 |
| 诱导互动 | 点赞 / 关注我（硬要） | 用「评论区说一个」自然钩子 |
| 贬低同行 | 踩一捧一 | 不踩任何工具/平台，只讲自己体验 |

### 6.2 投资类红线（投研背书内容必守）
- 只输出「怎么看」的观点，不荐股、不喊单、不承诺收益、不出现「稳赚/翻倍/跟买」。
- 投研系列不进首发，单独成栏目作信任背书，发前必过违禁词扫描 + 人工复核。

### 6.3 虚拟品红线
- 不承诺收益、不教违规上架，只讲合规选品 + 上架 SOP。
- 选品三件事：不碰版权内容、类目选对、新规应对（见 D3 样稿）。
