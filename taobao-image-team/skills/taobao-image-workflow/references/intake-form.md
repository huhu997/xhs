# 接单需求单（intake form）

接到淘宝上架图需求时，用这份模板向客户收集信息。能填多少填多少，缺的用默认值补。

```
【1. 基本信息】
- 商品名 / 标题：____________________
- 品类：□服装 □美妆护肤 □数码3C □食品零食 □家居日用 □母婴 □虚拟品(教程/资料) □图书课程 □其他：____
- 目标平台：□淘宝(默认) □天猫 □拼多多 □京东（多平台需分别出规格图）

【2. 卖点（最重要，决定图能不能卖货）】
核心卖点 1：____________________
核心卖点 2：____________________
核心卖点 3：____________________
（主图 points 建议 3–4 条，最多 5 条；详情分段可另给 3–5 段）

【3. 价格与档位】
- 售价 / 到手价：¥______
- 活动标签：□限时特惠 □新品 □爆款 □包邮 □其他：____
- 是否有多档位（用于详情 cards / 导购 tiers）：□单档 □2 档 □3 档
  档位 1：名称____ 价格____ ｜ 档位 2：____ ｜ 档位 3：____

【4. 风格偏好】
- 参考风格：□深蓝科技风(默认) □Apple极简 □国潮 □ins风 □高端奢华 □可爱萌系
- 主色：______________（不填则用模板默认的深蓝 + 橙红）

【5. 产品图素材（可选，决定要不要左图右文）】
- □不提供 → 出「纯文案参数卡」（中文不糊字，可直接上架；虚拟品/参数图解首选）
- □提供白底/纯色产品实拍图 → 填 product_img 绝对路径，主图+导购首图自动左图右文
- □生活场景图 / 带水印图 → 需客户先自行去背景去水印（本机无 rembg/cv2，工作流不修图）

【6. 图量需求】（本工作流默认产出，见下方「标准交付规格」）
- □标准全套：主图×1 + 白底图×1 + 3:4 导购图×5 + 详情长图切片×N（默认勾选）
- □另需主图多卖点变体×N（复制订单改文案多次出，平台上限 5 张）
- □另需主图视频（可选，1:1 / 3:4，另走 HyperFrames）
- □另需大促 banner（指定节日：____）

【7. 交付】
- 格式：□PNG(默认, 本机渲染) □JPG(合成长图时) □HTML 源稿(可改)
- 交付方式：□云盘 □压缩包 □直接发图
- 交期：____ 天
- 预算/报价档：□基础 □标准 □高级（见 pricing.md）
```

## 标准交付规格（对齐 2026 新版，勿再写 1080 / 750 拼接）

| 产物 | 规格 | 数量 |
|---|---|---|
| 主图 | 1440×1440 | 1 张（变体按需另出） |
| 白底图 | 800×800 | 1 张 |
| 3:4 导购图 | 1440×1920 | 5 张 |
| 详情长图切片 | 1440 宽，单张高 ≤2800 | 多张 |

> 平台的「主图最多 5 张」「导购图最多 5 张」是**上传上限**，不是本工作流一次出图的数量。

## 收齐后
1. 落成一式 `order.json`：**直接复制 `references/categories.md` 对应品类的片段**，或改 `examples/order_example_*.json`（真实 schema）。字段表见 `SKILL.md` 的「order.json 字段」。
2. 有产品图就填 `product_img` 绝对路径（见 SKILL.md「补产品图」节）。
3. 走 SKILL.md 的三步出图 + 7 步工作流。
