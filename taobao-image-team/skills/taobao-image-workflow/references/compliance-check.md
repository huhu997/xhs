# 淘宝/闲鱼 上架合规自查清单

> 出图与文案发布前过一遍。源自多 SKU 实测：0 条硬违规可上架，warn 词仅提示复核。

## 一、硬违规（命中即不可发）

- 境外 AI 工具名：**ChatGPT / Claude / Gemini / Sora / Copilot / Midjourney / Cursor / Codex / DALL·E** 等一律不出现
  - 替代表述：「支持 MCP 协议的 AI 工具」「WorkBuddy / CodeBuddy」等国内合规名
- 违禁品类 / 虚假承诺：**包过 / 保过 / 考证 / 培训（按需复核类目）**
- 站外引流：**微信号 / 加V / 外链 / 支付宝 / 银行卡 / 线下**
  - 聊天里也不要发，命中即回「请通过平台沟通」；文件直接在平台聊天发

## 二、warn 词（淘宝属合法表述，仅人工复核语境）

- 服务 / 课程 / AI助手 / 代写 / 源码 / 部署 / 代做
- 处理：**代做档写成「按单交付」**；「源码」→「代码」；「部署」→「接入/配置」
- 标题禁用 emoji / 箭头符号（淘宝描述里 → 允许，但闲鱼规则下按 emoji 处理，注意区分平台）

## 三、通用自查（每包发布前）

- [ ] 内容自产/重制/授权，非盗版；不承诺任何收益（加「请理性购买」声明）
- [ ] 标题/描述无境外工具名、无培训/包过/模型部署词
- [ ] 无 emoji 堆砌、无站外引流词
- [ ] 类目在千牛可发（发不了改邻近类目，别硬发）
- [ ] 虚拟商品不支持 7 天无理由，已在售后写清方式

## 四、标题规则

- ≤30 字，**前 10 字权重最高** → 核心搜索词放最前（如「2026AI变现赚钱教程 副业项目 零基础 网盘自动发货」）
- 覆盖买家搜索词：品类 + 利益点 + 场景

## 五、聊天红线

- 不主动要微信/QQ/外链；对方给也不回真实联系方式
- 文件/资料直接用平台内置发送，避免触发封号
