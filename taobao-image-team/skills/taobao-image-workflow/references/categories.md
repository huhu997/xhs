# 品类预设库（可接单做任意品类）

每类给出：① 典型图位清单 ② 卖点文案范式 ③ 可直接用的 **order.json 片段**（整份文件就是下面的 JSON，存成 `order.json` 即可）。

> ⚠️ 字段以 `examples/order_example_case.json`（手机壳）为准，顶层结构如下，**不要**再套 `main`/`detail` 旧字段：
> `sku / badge / title_line1 / title_hl / sub / points[] / price / foot / detail[] / guide[] / whitebg_title / whitebg_sub / product_img(可选)`
