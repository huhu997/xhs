# 交付 SOP（接单 → 交付 → 售后）

> 适用于「帮别人出淘宝上架图」或「卖铲子：把本工作流卖给店主」。自用可精简。

## 一、接单 intake（见 intake-form.md）

收齐：品类 / 商品名 / 卖点（3–4 条）/ 价格档位 / 是否有实物图 / 目标平台（淘宝/闲鱼/小红书）/ 交付格式

## 二、出图（本工作流）

1. 填 `order.json`：直接复制 `references/categories.md` 对应品类片段，或改 `examples/order_example_*.json`（真实 schema，字段表见 SKILL.md）
2. `python scripts/fill_template.py order.json --out <客户目录>`
3. `node scripts/render_all.mjs <客户目录>` → `python scripts/slice_images.py --root <客户目录>`
4. 抽查：主图/导购图/详情图中文是否清晰、无乱码、无裁切异常；带 `product_img` 的另查产品图有无水印/杂乱背景

## 三、交付物清单（发给客户）

- 1:1 主图 ×1（另出白底图 ×1，共 2 张方形图；多卖点可生成主图变体，按需加）
- 3:4 导购图 ×5
- 详情图切片（1440 宽，多张）
- 主图视频（可选，1:1 + 3:4）
- 上架表单 .md（标题/价格/SKU/发货文案，客户直接抄）
- 合规自查表（已勾选）

## 四、自动发货（虚拟商品，卖给 C 端时）

- 发货文案模板：「您购买的【X】已就绪：{网盘链接} 提取码 {提取码}，有问题随时联系」
- 千牛绑定自动发货工具（阿奇索/极速宝）

## 五、买家操作手册（随商品交付）

- 打开网盘链接 → 保存/下载 → 按教程路径实操
- 进阶版：每周更新补发新链接；旺旺答疑
- 售后：虚拟商品不支持 7 天无理由，但补发/答疑负责到底

## 六、售后承诺文案（可改入模板）

- 虚拟商品不支持 7 天无理由，但答疑/补发一定到位
- 进阶版每周更新，更新后补发新链接
- 旺旺沟通，响应及时

## 七、卖铲子模式（把工作流卖给店主）

- 交付：`taobao-image-workflow` skill 去署名打包 + 30 分钟上手陪跑
- 定价参考 pricing.md（基础 ¥29 / 标准 ¥99 / 高级 ¥299；整包 ¥199–499）
- 强调：本机渲染、中文不糊字、一键出全套、可白标
