# 淘宝上架素材规格（2026 新版）

> 本工作流出图即按此规格，发布前逐条核对。规则来源：淘宝 2026 新版素材要求。

## 一、六类素材规格

| 素材 | 比例 | 尺寸 | 数量 | 用途 · 关键点 |
|---|---|---|---|---|
| 1:1 主图 | 1:1 | **1440×1440 起**（最低 800×800） | 最多 5 张 | 商品详情页首屏 + 放大镜 |
| 3:4 导购主图 | 3:4 | **1440×1920 起** | 最多 5 张 | 手淘推荐/猜你喜欢/微详情；**不是** 1:1 主图 |
| 白底图 | 1:1 | **固定 800×800** | 1 张（置主图第 5 位） | 纯白底、主体完整、无水印/文字/阴影/logo；过审后自动进频道与大促 |
| 主图视频 | 1:1 / 3:4 / 9:16 | MP4，1080P，≤50MB | 最多 5 个 | 5 秒–5 分钟；1:1、3:4 详情页可播；9:16 只进公域 |
| 详情图 | 宽 ≥1440，**单张高÷宽 ≤2** | 本工作流 1440 宽切 ≤2800 高 | 多张切片 | 超比例会被系统**裁剪**；禁止 750 宽超长单图 |
| 导购标题 | —— | **≤30 字符** | 1 条 | 品牌 + 品类词 + 利益点，前 10 字权重最高 |

## 二、本工作流对应产出

| 脚本/模板 | 产出 | 规格 |
|---|---|---|
| `fill_template.py` → `主图_Sx.html` | `主图_Sx.png` | 800×800 CSS @1.8x → **1440×1440** |
| `白底图_Sx.html` | `白底图_Sx.png` | 800×800 CSS @1x → **800×800** |
| `导购图3x4_Sx.html` | `导购图_Sx_1~5.png` | 720×960 CSS @2x → **1440×1920 ×5** |
| `详情图_Sx.html` | `详情图_Sx_01~.png` | 750 宽 @1.92x → **1440 宽**，按段切片 ≤2800 高 |
| （可选）`make_video` 封装 | `主图视频_Sx_1x1/3x4/9x16.mp4` | 1080×1080 / 1080×1440 / 1080×1920 |

## 三、两个最容易踩的坑

1. **详情图高宽比 >2 直接裁剪**：1440 宽单张最高 2880px，超了底部被截。本工作流自动按段落边界切片，单张 ≤2800px（比例 1.94，留余量）。
2. **9:16 视频不在详情页显示**：只在首页推荐/微详情露出。想进详情页必须同时备 1:1 或 3:4 版本。

## 四、发布前素材自查

- [ ] 1:1 主图至少 1 张已传（工作流产出 1 张；平台上限 5 张，多卖点变体按需复制订单另出），首图无边框/牛皮癣/联系方式
- [ ] 白底图（800×800，工作流单独产出）已传至白底图位，纯白底无文字水印阴影
- [ ] 3:4 导购图 5 张已传（推荐流量位）
- [ ] 详情图每张宽 ≥1440，单张高/宽 ≤2
- [ ] 主图视频详情页用的是 1:1 或 3:4（非 9:16）
- [ ] 导购标题 ≤30 字，品牌 + 品类 + 利益点
