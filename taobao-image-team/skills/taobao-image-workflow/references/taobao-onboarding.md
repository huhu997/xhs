# 千牛手动上架操作指南（淘宝虚拟/服务商品）

> 配合本工作流的成品图使用。每包就是「复制表单 → 填千牛」的重复动作。

## 第 0 步：开店与保证金（首次）

1. 千牛 → 免费开店（个人店，身份证实名）
2. 保证金：交 1000 元基础，或 0 元开店 + 保证金保险（约 30 元/年）
3. 完成支付宝实名 + 手机验证

## 第 1 步：确认类目与资质（每 SKU 必做）

- 千牛 → 发布宝贝 → 搜类目关键词（如「教育培训」「设计服务」）
- 选中叶子类目后看是否需资质（营业执照/出版物经营许可证）
- 个人店发不了的子类目 → 改邻近类目：课程试「教育培训 > IT/互联网/设计」，服务走「设计服务/生活服务/企业服务」
- 拿不准找千牛人工客服确认，别硬发（错放类目=违规扣分）

## 第 2 步：发布宝贝

- 商品管理 → 发布宝贝 → 搜类目进入填写页
- 逐项对照上架表单：标题 / 价格 / SKU 规格 / 库存 / 主图 / 详情

## 第 3 步：1:1 主图（1440×1440，平台上限 5 张）

1. 第 1 张放 `主图_Sx.png`（1440×1440，工作流产出 1 张）
2. 需要多卖点主图 → 复制 `order.json` 改 `sku`（如 Sx-2）+ 文案，重跑三步出变体；最多凑到 5 张，可拖拽排序
3. `白底图_Sx.png`（800×800）单独传「白底图」位，过审后自动进频道与大促
4. 首图不加边框、牛皮癣、联系方式

## 第 4 步：3:4 导购主图（5 张 · 1440×1920）

- 导购图_Sx_1~5.png：手淘推荐/猜你喜欢/微详情卡片，**只作用于推荐流量位**，替代不了 1:1 主图
- 顺序：主视觉 → 交付内容 → 交付流程 → 售后保障 → 档位参考

## 第 5 步：主图视频（可选，建议做）

- MP4 / 5 秒–5 分钟 / 1080P / ≤50MB / 最多 5 个
- **详情页展示用 1:1 或 3:4**；9:16 只进公域推荐

## 第 6 步：SKU 规格与价格

- 表单「价格与 SKU 规格」逐行加到「销售规格」（如 基础版/进阶版）
- 服务类按档位设，拍下后旺旺沟通需求再交付
- 运费：虚拟商品 0 运费，建「虚拟商品免邮」模板

## 第 7 步：发货设置（虚拟商品自动发货）

1. 服务市场搜「自动发货」（推荐：阿奇索 / 极速宝），建自动发货模板
2. 模板内容 = 网盘链接 + 提取码 + 使用说明（照抄表单发货文案）
3. 宝贝「发货设置」选「使用自动发货」绑定模板
4. 发测试订单验证（买家付款 → 自动收链接）

## 第 8 步：详情页（1440 宽切片 · 高/宽 ≤2）

- 顺序上传：详情图_Sx_01.png → _02.png（按切片编号依次传）
- 不用的 750 宽超长单图已废弃；也可用 `stitch_long_image.py --width 1440` 合成长图备用
- 文字版描述可粘贴表单「详情描述」（与切片图二选一或都用）

## 第 9 步：冷启动

- 前 3–5 单请朋友/老客拍（**不要刷单**，严查虚假交易）
- 每天看生意参谋免费版：搜索人气、点击率
- 跑通后直通车小预算（日 50 元）测 3–5 词，删无点击加有转化

## 附录：改图重出

1. 编辑对应 HTML（主图_Sx / 导购图3x4_Sx / 白底图_Sx / 详情图_Sx）
2. `node render_all.mjs` 渲染 → `python slice_images.py` 切片
3. 自动按规格出图，无需手动调尺寸
