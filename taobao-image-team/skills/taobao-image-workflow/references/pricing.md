# 报价模板（接单用）

成本几乎为零（本机 Chrome 渲染，不依赖任何云端生图 API），报价即毛利。按图量和档位分层。

## 成本基线
| 项目 | 成本 | 说明 |
|---|---|---|
| 主图 / 导购 / 白底 / 详情 HTML 渲染 | ¥0 | 本机 Chrome CDP 截图，中文不糊字 |
| 产品图（可选） | ¥0 | 客户提供白底实拍图；或用 Gemini 免费档生通用渲染图 |
| 人工（你审+微调） | 时间成本 | 主要投入 |

> 本工作流默认纯 HTML 出图，**Gemini / 极睿 / 稿定均非必需**，只在客户要"带产品图的商品图观感"时才涉及。

## 三档报价（单 SKU 全套上架图）
| 档位 | 含图（对齐工作流真实产出） | 参考报价 | 毛利 |
|---|---|---|---|
| **基础** | 主图×1 + 白底图×1 + 详情长图切片（纯文案参数卡） | ¥29–49 | 高 |
| **标准** | 基础全套 + 3:4 导购图×5 + 上架表单 + 合规自查表 | ¥99–199 | 高 |
| **高级** | 标准全套 + 产品图叠加（`product_img` 左图右文）+ 主图多卖点变体 + 大促 banner + 多平台规格图 | ¥299–599 | 高（云端补强成本另计） |

> 平台「主图最多 5 张」是上传上限；本工作流一次出主图×1，多卖点变体需**复制订单改文案多次出**，按变体数另计费。

## 计价补充
- **多 SKU**：第 1 个全价，后续每个 +¥15–30（复用模板，边际低）。
- **多平台**：每加一个平台规格图 +¥20–50。
- **加急**：当日/次日交付 ×1.5。
- **云端补强**（客户坚持要中文密集文案图精修 / 换背景，需极睿/稿定/Seedream）：成本按实际 + 30% 服务费转嫁。
