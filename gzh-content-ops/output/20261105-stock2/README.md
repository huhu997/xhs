## 这一轮真正值钱的三处返工

1. **S5 一审打回第 2 条**：我写了"钱从防守那半边挪到了进攻那半边"，但同一节的上一段刚说过"这份数据只有流入端，排不出资金在撤离谁"。**自己跟自己打架**。改法不是换词，是把主语从"钱"换成"涨跌分布"。
2. **跨载体不一致**：正文把"另外 2 只停牌"改成"原因我没逐一核实"（因为数据源根本没有停牌字段），但视频脚本三处还在断言停牌。同一个号同一天发两个载体互相矛盾，比单个错误更伤。
3. **封面挂着被毙的结论**：合规打回"换座位"之后，封面主标题还是这五个字，插图中间还画了个"换座"箭头。**文字改了、图没改，等于把打回项放到了最大字号上。**

## 数字口径（这篇的全部数字都从这里来）

- 涨跌家数：**逐股扫描**（5927 只扫描池，剔除停牌与无成交后 5573 只有价格）→ 4869 涨 / 624 跌 / 80 平
- 涨跌停：**东财封板池 tc 口径** → 涨停 **84** 只 / 跌停 **0** 只（逐股阈值扫描会得 86 / 3，两套数不许混用，全文只用 84）
- 昨日封板：118 只 → 今日取到 **116** 只样本 → 95 只上涨（**81.9%**）/ 23 只再涨停 / 中位数 4.29% / 平均 4.42%
- 资金流：**只有流入端**，没有可比的流出端（`flow_out` 六项全为正数，是"净流入最少"，不是净流出）
