# 08 · 视觉排版候选（3 套）

> 角色：gzh-visual　|　篇目：20261105-stock2《昨天封板的票，今天八成还在涨》
> 依据：`themes.md` 16 主题 × 8 版式；`cover-spec.md` 尺寸与安全区
> **避撞声明**：同日上一版（`output/20261105-fullrun/`）已用 **实战墨绿 `#1F4A3C` × L4 时间轴**（深绿满铺封面 + 暖米字）。本轮三套候选**全部换主题**，版式也不复用 L4。

## 候选 ① 财经严肃 × L8 数据看板　★ 推荐

| 项 | 值 |
|---|---|
| 主题 | 8 · 财经严肃 |
| 主色 | `#0E2A47` 深藏青 |
| 底纸色 | `#F4F1EA` 报表纸 |
| 强调色 | `#C8A24B` 旧金 |
| 版式 | L8 数据看板（数字块 + 条形读数 + 分区卡片） |

**一句话理由**：这篇通篇是读数——涨跌家数、涨停家数、五个指数、十条板块、五个资金行业，用"看板"承载最不浪费；深藏青＋报表纸＋旧金，是 A 股盘后该有的严肃感。

**为什么适合这篇**：
- 正文本身就是一张表，L8 的"数字块"能把 4869 / 624 / 84 / 0 / 95 / 81.9% 一眼排开，读者扫码式阅读即可拿到全部信息。
- 深藏青是无彩色相的高冷色，**不参与涨跌语义**；红涨绿跌可以干净地留给定性的数据色（上版绿主题被迫把"跌"降级成灰，这版能把绿还给"跌"，更符合 A 股读者直觉）。
- 浅底报表纸封面与上版的深绿满铺封面**第一眼完全不同**，同一账号连发两天不会撞脸。
- 情绪基调对得上：旧金细线＋大量留白＝"我盯着一个没人看的数"的克制，而不是牛市红或崩盘绿。

## 候选 ② 卡片信息卡 × L3 卡片流

| 项 | 值 |
|---|---|
| 主题 | 3 · 卡片信息卡 |
| 主色 | `#B4802A` 赭金 |
| 底纸色 | `#FBF6E9` 米白 |
| 强调色 | `#1F4A3C` 墨绿 |
| 版式 | L3 卡片流（信息卡堆叠） |

**一句话理由**：把"三个数 / 换了座位 / 81.9% 的边界 / 反过来那 18%"切成四张卡，手机上滑一张懂一件事，适合转发给不看长文的人。

**为什么适合这篇**：文章天然有四个可切块的结论，卡片化能强化"记下来"的动作；暖米底比冷色更亲和。
**风险**：配色偏"干货清单"气质，会削弱这篇"盘后冷静"的调性；且强调色又是墨绿，与上版同色系，**避撞不够彻底**。

## 候选 ③ 极简白 × L1 单栏通读

| 项 | 值 |
|---|---|
| 主题 | 9 · 极简白 |
| 主色 | `#1A1A1A` 近黑 |
| 底纸色 | `#FFFFFF` 纯白 |
| 强调色 | `#155E9E` 靛蓝 |
| 版式 | L1 单栏通读 |

**一句话理由**：全篇只留字与数，不靠任何装饰撑场面——最贴合"我只把数摆整齐"的作者姿态，也最耐读。

**为什么适合这篇**：长文（约 2600 字）+ 大量并列数据，L1 的行距与节奏最省力；白底黑字在信息流里反差最大。
**风险**：视觉记忆点最弱，封面难做出辨识度，两天连发容易"看不出是做过的"。

## 推荐结论

**采用 ① 财经严肃 × L8 数据看板**，并已按下述方案直接出成品（不等第二轮选择）：

- 封面：浅报表纸底 `#F4F1EA` + 深藏青衬线大字 + 旧金细线，底部一条**真实涨跌分布条**（按 4869 : 624 的比例排色，装饰不载字），关键内容压中间 42% 安全区。
- 插图：16:9 双面板「防守端 / 进攻端」横向条形读数，同一比例尺，左边短条（跌）右边长条（涨），中间一个"换座"箭头——把"钱换了个座位"画成一张能读的图。
- 正文：L8 看板式，`01–07` 编号分区 + 读数块 + 条形列表，全内联样式，可直接粘进公众号。

### 数据色（与主题色分离，A 股惯例，不许反）

| 语义 | 色值 | 用在哪 |
|---|---|---|
| 涨 / 正向 | `#D9462B` 朱红 | 上涨家数、涨停家数、光伏与 AI 板块涨幅、资金净流入、81.9% |
| 跌 / 负向 | `#2E7D5B` 松绿 | 下跌家数、权重与红利板块跌幅、反转的 21 只 |
| 中性 / 弱化 | `#8B8577` 暖灰 | 平盘、跌停 0、次要文字、表注 |
| 结构 | `#0E2A47` 深藏青 | 标题、正文主字、分隔线、看板描边 |
| 点睛 | `#C8A24B` 旧金 | 刊头、编号、细线、金句竖标 |

> 深藏青**只做结构**，不表示涨也不表示跌；绿只表示"跌"，红只表示"涨"，灰只表示"无方向"。
