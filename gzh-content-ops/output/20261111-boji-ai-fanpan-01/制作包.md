## 零、这稿为什么重写（不做第五轮润色）

用户四轮反馈：**假大空**（框架套人设）→ **很平**（无起伏）→ **磨三年夸张**（数字挪用）→ **重新写吧，我以为可能是模型的问题**。

前三轮我一直在修规范、补细节、改措辞，但**文章的讲法没变**：都是「一条片子 → 所以我的方法论是默认值」。读者拿到的是一套道理，不是一段经历。v3 里最典型的是中段那句「薄肌不给我这个选项。到点，垫子铺开，人已经在上面了」——它正确、通顺，但没有画面之外的东西。

v4 换讲法：**不写"我悟到了什么"，写"我删掉了哪一句、为什么删"。**

- 全文只有一件具体的事：五句话压进 26 秒，删掉「审美早变了，不是人形货架」。
- 有取舍（删的还是我最想说的）、有代价（怕被截图骂）、有判断（留下的四句每句只答"我能不能做到"）。
- 力度来自**守与舍**，不来自"三年磨一剑"。三年只出现在薄肌那一句事实里，不与片子绑因果。
- 「翻盘」只出现一次，且是往下压：「我觉得没那么大——无非是把商量的次数减到零。」

**取材纪律**：五句/四句、四张卡文案、26 秒 / 9:16 / 2.8MB / renders / 时间戳 / 两小时 / 三步 / 工具换过 / 三年每周四晚四十分钟 / 没私教 / 不称克数 / 脚本没存模板——全部有出处（`视频01_宣言/脚本.md`、`发布包.md`、第 2 集自述）。**没有版本数、没有具体报错、没有"那天状态如何"这类无佐证细节。**

## 三、张力三问（`zhangli.md` 第六节）

1. **读者第 3 行会以为讲什么？在哪段推翻？**
   以为讲「怎么做出一条 26 秒的片子」（渲染完了、四张卡、两小时）。在「两个小时里，等渲染只占一小段」推翻——重心不是工具，是删。
   **第二层落差**在「所以这两件事不是谁帮了谁」：读者以为要收成"薄肌给了我做片子的能力"，作者否掉，改成「同一个动作：把商量的次数减到零」。
2. **最慢 / 最快各是哪段？**
   最慢：四张卡逐句解释那一段（约 260 字，含每句卡文案 + 为什么留）。最快：「剩下的时间都在删。」「明天干这个。」「那是我最想说的一句。」（≤10 字）。
3. **结尾是总结还是口子？**
   口子。「删掉那句还在脚本最后一行」「得先把脚本存成模板」「明天干这个」。无总结、无升华、无引导关注。

**五条硬指标**：落差 2 处 ✓ ｜ 每 300 字 ≥1 个 ≤12 字极短句独立成段 ✓ ｜ 密度差（四张卡写透 ≈260 字，薄肌 60 字掠过）✓ ｜ 开头 3 行钩子（渲染完 → 原本五句 → 删的是哪句，无介绍无铺垫）✓ ｜ 结尾留口子 ✓。
