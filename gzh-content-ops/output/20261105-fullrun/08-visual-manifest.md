## 三、渲染方式（可复现）

- **方式：本地 HTML/CSS 渲染 + 系统 Chrome headless 截图。**
- **明确声明：本轮所有图片均为本地 HTML 渲染，非 AI 生图，无需「AI 生成」标注**（写在此处避免交付/发布环节误标）。
- 渲染器：`C:/Program Files/Google/Chrome/Application/chrome.exe`
- 命令模板：

```
chrome.exe --headless=new --disable-gpu --no-first-run --no-default-browser-check \
  --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1880,800 \
  --user-data-dir=<独立临时目录> \
  --screenshot=<输出.png> \
  file:///<08-cover.html>
```

  插图把 `--window-size` 换为 `1600,900`。两张各用独立 `--user-data-dir`，**不占用 9222 端口、不触碰后台 Opera 的 `.gemini-opera-profile`**。
- 字体：正文 `Noto Sans SC` / `Microsoft YaHei` / `PingFang SC`；衬线标题 `Noto Serif SC` / `Songti SC`；数字 `Helvetica Neue` / `Arial`。
- **复核记录**：两张 PNG 均经 `ls -l`（非 0 字节）、`Read`、`ViewImage` 目视复核；PNG IHDR 实际像素尺寸已用脚本校验为 **1880×800** 与 **1600×900**；中文无乱码、无裁切、无重叠。正文 HTML 另出过一张临时自检截图目视确认 L4 时间轴与看板渲染正常（临时文件在系统 Temp，非交付物）。
