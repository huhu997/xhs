### 对 `themes.md` 第三节默认选型规则的挑战（附理由）

默认给了三条相关规则：「政策/宏观/行业（金融号高频）→ 财经严肃 × L1/L8」「带数据 → 数据看板 × L8」「复盘/踩坑 → 实战墨绿 × L1/L4」。

- **保留「复盘 → 实战墨绿」**，但把 L1 换成 **L4**：盘后笔记有天然时序（开盘/盘中/收盘/盘后），时间轴比单栏更贴体裁。
- **刻意不取「带数据 → 数据看板 × L8」**：本篇的数据不是为了陈列，而是为了论证「一个反差」；L8 把叙事拆成一堆数字块/仪表盘，会弱化第一人称自嘲的人声。更关键的是，出图硬约束是「图内少放数字、精确数字留正文表格」，而 L8 强依赖图表，二者直接打架。
- **保留「财经严肃」作候选 ① 但不推荐**：它把题材当市场解读，却和账号自嘲人设冲突，见上表风险栏。

### 我的推荐：**第 ② 套（实战墨绿 × L4 时间轴）**

理由：账号人设（第一人称 + 自嘲 + 盘后手记）压过题材的「金融」标签。② 是唯一同时接住「复盘体裁 / 手记语气 / 红涨语义」三者的组合——① 太端着撞人设，③ 装不下数据。

风险可控，化解办法：
- 「绿主色 vs 普涨」的语义误导 → 把强调色朱红用在「4869 涨 / 上涨家数」等正向数据点上，**绿只作背景与结构色、不承载涨跌语义**；下跌（625）用中性灰而非绿标注，避免二次混淆。
- L4 时序风险 → 若正文确无多事件串联，把 L4 理解为「盘后时间线节点」（开盘 / 收盘 / 盘后自嘲三个节点）而非严格事件轴，仍成立。

### 失败定位（依据 `gemini-image.md` 第七节）

- 代理层是通的：Stdout 明写 `检测到代理 [Linsoc/v2ray]: http://127.0.0.1:1080`，说明 `unset` 生效、1080 可用，**排除「代理出口错 / 吃到沙箱 2233」**（该情况应报 502）。
- 失败在会话/令牌层：`Unable to connect. Is the computer able to access the url?`，脚本自动轮换 Cookie 一次后仍失败。
- 与预检 `00-env-precheck.md` 第 36 行是**同一个错误**：`--login` 阶段 Token 验证即报此错、脚本仍标「登录完成」。按 `gemini-image.md` 第七节第 3 行，`--login` 读到 1PSID 但令牌验证失败 → **Opera 里的 Google 会话本身过期**，或出图请求经代理到 Gemini 后端不通。
- 即：Cookie 三项抓到了，但会话令牌已无法完成实际出图请求；这是会话态问题，不是脚本参数/代理配置错误。

### 降级建议（**不拍板，交团长 → 用户点选**）

按 `gemini-image.md` 第六节降级链 `1 → 2 → 3`。以下为倾向性建议，**本文件不做降级决策**，请用户从选项里择一：

- **选项 0 · 先修链路 1（零成本，我建议先试一次）**：让用户在 Opera 窗口内重新登录 Google（确认能看到 Gemini 对话界面）→ 重新 `--login` → 再跑一次本探测命令。理由：失败定位明确指向 Opera 会话过期，手册给了对应修复动作；一旦修好仍走零积分主路线，符合「只要链路 1 可用就不用 2」。代价：需用户手动在 Opera 操作一次，且复测仍可能失败。
- **选项 1 · 降到链路 2（WorkBuddy `ImageGen`）**：单张 5–10 信用分、封面+多张插图累计成本不低；图角带平台水印，正式发布前需处理；配色靠 prompt 指定 hex 无法绝对精确，与「配色同源、禁止临时换色」硬约束有张力。
- **选项 2 · 降到链路 3（本地 HTML/CSS 渲染，`cover-spec.md` 路线 B）——若必须降级，我倾向这一级**，理由三点：
  1. 本篇核心视觉是「天平 / 权重股 vs 全市场」这类**几何信息图形，非写实场景**，恰是本地渲染强项（路线 B 定位「纯排版型卡片、中文绝对清晰」）；
  2. 配色由 CSS hex **绝对锁定**，100% 满足「封面 / 插图 / 正文三处同源同款」，中文标签零糊字；且 `cover-spec.md` 第四节明写「需要精确数字时用路线 B」，对这篇数据密集稿反而是加分；
  3. 零积分、零水印、无会话依赖，一次性清掉链路不确定性。代价：没有 3D/写实氛围质感，视觉冲击弱于生图。

- **我不建议把链路 2 作为降级首选**：既要烧积分又带水印，且 prompt 指定色值不保证精确，在三套候选都强调「配色绝对同源」的前提下性价比最低。是否跳过 2 直接到 3，请用户拍板。
