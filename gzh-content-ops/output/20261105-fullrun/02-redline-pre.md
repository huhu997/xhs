## 1. 财经复盘稿特有红线（硬清单）

- **不点买卖**：全文不出现"买入/卖出/加仓/减仓/拿住/上车/抄底/进场"等动作指令。
- **不预测点位/涨跌**：不写"明天会…""下周看 X 点""大概率涨/跌""要变盘了"。
- **不暗示个股操作**：不点具体个股代码/名称做多空判断；可提"权重/大市值/板块"现象，但不落到"可以拿/别碰"。
- **不给"该怎么操作"的指令**：不写"建议…""可以关注…""不妨…""接下来要…""盯着…"。
- **不承诺/暗示收益**：不写"稳赚/跑赢/躺赚/跟着做"。
- **观点留余地**：第一人称"我"可以，但个人判断加"我觉得/在我看/可能/我不确定"，别写成确定性结论。
- **不做阴谋论揣测**：不指认未证实主体（见第 2 节），不蹭敏感、不拉踩同行。
- **必带免责声明**：正文文末 + 口播结尾都要落，骨架见第 6 节。

## 2. 措辞雷区｜禁用 → 替代表达（上一轮真实被打回过的词，逐词对照）

| 禁用（曾打回） | 踩线原因 | 替代表达（可直接抄） |
|---|---|---|
| 托市 | 暗示 unseen 主体操纵＝未证实传闻 | 只写现象：「权重股相对抗跌」「上证仅涨 0.10%」；不引入主体 |
| 被托着 | 同上，被动式更隐蔽，照样打回 | 「指数收在 +0.10%」「权重板块微涨」——陈述数据即可 |
| 那只手 / 这拨人 | 指认未证实主体、带站队 | 删去，改「权重板块」「大市值个股」等可查对象，或直接不提 |
| 进场 | 买卖动作暗示＝"上车/抄底" | 「有资金回流迹象」「成交较前一日放大」，或干脆只陈述涨跌家数 |
| 全在跌幅榜上 | "全"绝对化，且与 4869 涨 / 625 跌 事实矛盾 | 「625 只下跌」「下跌的是少数」「部分板块收跌」 |
| 全在跌 | 同上，绝对化 + 数据失真 | 「收跌 625 只」「下跌个股集中在…（有口径才写）」 |
| 也在跌 | 顺着"全在跌"的误导链条，口径不清 | 「同步收跌的为…」「另一边 X 只下跌」——给数字、给范围 |

口诀：**主体不写、动作不写、"全/也"不写；只写可查的数字和"权重/板块"这类中性对象。**

## 3. 数据口径红线

- **同口径同来源**：4869 / 625 / 0 / +0.10% 必须同一数据源、同一时点（收盘）。开头标注口径，如「截至收盘，按 XX 行情终端全 A 统计」。
- **不混用不标注**：涨跌家数用 A 源、指数用 B 源、板块用 C 源却不说明 → 打回。混用必须逐处标来源。
- **不写无因果链的"因为 A 所以 B"**（如"因为权重护盘所以指数没涨"缺证据）：要么删，要么写成「我观察到 A 与 B 同时出现，不确定是否有因果」。
- **不用未核实的占比/九成类模糊表述**（"九成个股在涨""几乎全线上涨""大多数人都…"）：改用可查数字 4869 / 625 / 0，或删。
- **主线表述要自洽**：「指数只量出权重股情绪，量不出全市场」作为"我的理解/观察"呈现，别写成被证实的定律；4869 涨 vs 指数微涨正好支撑"指数与全市场背离"，**千万别顺手写成"全市场都在跌"**（与数据打架）。

## 4. 标题红线（按 biaoti-gongshi.md 第四节，命中即整篇打回，不许"正文干净就放过"）

**禁用词**：保证、一定、必然、稳赚、翻倍、暴涨、暴跌（作断言时）、所有人、必须、彻底、唯一、最强、第一、抄底、上车、满仓、闭眼买；叠加通用绝对化：最、第一、绝对、肯定。

**禁用结构**：
- 预测具体点位或涨跌幅（"下周一必破 3500"）
- 个股买卖暗示（"这三只可以拿"）
- 虚构人设故事（"我有一个朋友…"）
- 威胁句式（"你不看就晚了""再不知道就亏大了"）
- 连续两句以上对仗（"不是…而是…"×2 即超标）

正向提示（第七节）：A股每日复盘首选「场景切片 + 数字反差」，避开「时间锚定」。标题 15–24 字，钩子放前 12 字。标题单独过一遍第四节再交。

## 5. 视频号口播文案红线

- **话题标签**：只用中性事实标签（#A股复盘 #盘后笔记 #上证指数）；禁用带方向/绝对化/诱导的标签（#牛市来了 #必涨 #抄底 #满仓）。不蹭敏感话题。
- **引导语**：不诱导分享/转发/集赞（"转发给朋友别踏空""点赞明天涨"）；不写"关注我带你…""评论扣 1 领…"等引流/割韭菜话术。
- **不构成投资建议落点**：口播结尾必须落「仅为个人盘后记录，不构成投资建议，市场有风险，决策自主、风险自担」。
- 与正文同标准：不预测点位/涨跌、不点个股买卖、不承诺收益、不用焦虑恐吓句式（"再不懂就被淘汰"）。

## 6. 免责声明句骨架（可直接抄，文末 / 口播结尾各落一次）

**标准版（正文文末）**：
> 本文只是我个人的盘后笔记，记录我看到的数据和一点想法，不构成任何投资建议，也不推荐任何个股。文中涨跌家数、指数涨跌幅等数据来自公开行情，不同终端口径可能有差异，请以交易所及行情软件为准。市场有风险，决策请自主判断、风险自担。

**自嘲短版（口播结尾 / 正文可选）**：
> 一个散户的盘后碎碎念，只记录、不荐股、不喊单、不预测点位。数据以行情终端为准，口径不同请自行核对。市场有风险，盈亏自负。
