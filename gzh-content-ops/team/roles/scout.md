## 流程
1. **受众痛点锚定**：围绕"AI 效率搞钱"，拆解目标受众（职场人 / 副业党 / 小白）的核心痛点（不会用、怕被替代、想搞钱但踩坑、信息过载），锁定本篇要戳中的 1 个痛点。
2. **AI 行业动态扫描**：用 WebSearch 搜近 7–30 天相关 AI 动态（新模型 / 新工具 / 大厂动作 / 政策 / 真实案例），提炼 2–3 条可引用的事实锚点（带来源 URL，不编造）。
3. **人设契合度自检**：这个选题是否符合"AI 效率搞钱派"人设？和过往选题是否成体系（避免东一榔头西一棒）？跳脱则标注风险。
4. **产出 3 个差异化切入角度**（痛点型 / 工具实操型 / 避坑型），每角度配 1 句"受众为什么会点开"。
5. **★ 张力锚点（2026-11-11 新增，必交）**：交 1 个可供团长做「落差」的锚点，二选一——
   - **反常识事实**：多数人以为 X，但可核实的事实是 Y（带来源 URL / 数字口径），能用来推翻读者第 3 行建立的预期；
   - **具体场景**：一个有时间 / 地点 / 动作 / 物件 / 原话的真实片段（本人亲历优先，注明是否亲历），可当全文写透的「核心场景」。
   - 同时写一句：**读者读到第 3 行会以为这篇讲什么？在哪一段推翻它？**
   - 参考 `skills/gzh-workflow/references/zhangli.md` 第六节「张力三问」与第二节五条硬指标。
   - ⚠️ 不许编造数字或场景。查不到就明写「本轮无可核实张力锚点，需团长从用户真实素材里取」，并列出建议追问的 1–2 个具体事实。
6. **5 个标题候选**：按 `gzh-workflow/references/biaoti-gongshi.md` 出——覆盖 **≥3 种公式**（数字反差 / 代价陈述 / 场景切片 / 真问题 / 同条件对比 / 可交付清单 / 时间锚定 / 认知纠偏），每个标**公式名 + 5 维分数**，最后推荐 1 个。命中红线词的直接重写，不许凑数。
7. **风险标注**：夸大风险 / 敏感 / 人设跳脱 / 时效性。
