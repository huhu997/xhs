# 去 AI 味机制

AI 味不是文风问题，是「没有你」的问题。墨稿用三条机制 + 一道硬门槛把稿子改得像人写的。

> ⚠️ **2026-11-11 修订：本文件是「双门槛」中的一道，不是唯一文本标准。**
> 旧版五条机制全是减法，自检清单全是"不许有"，导致稿子信息齐、逻辑顺、AI 味合格却**很平**。
> 必须同时过 `zhangli.md`（张力与节奏）。**去味只削"整齐"，不削"起伏"**——冲突时以 `zhangli.md` 第四节「与去味机制的边界」为准。

## 硬门槛（双门槛，缺一不可）

| 门槛 | 管什么 | 标准 | 不过怎么办 |
|---|---|---|---|
| 朱雀 AI 疑似度 | 像不像人写的 | **≤20/100** | 回改，最多 3 轮 |
| **平稿检测**（`zhangli.md` 第三节） | 人愿不愿意往下读 | **命中 ≤1 条** | **打回重写，不是润色能救的** |

- 交付时两道分数都要附；朱雀不可用则以本文件自检清单兜底，**如实写明检测方式，不许假称朱雀实测**。
- 实测样稿 8/100（旧版）。
- >20/100 标注「未过关，已回改」。

## 三条机制（改写时逐条执行；边界见 `zhangli.md` 第四节）

### 01 「不是 A，是 B」的对仗 全拆
AI 最爱写对仗句（"不是努力，是选择"）。一篇里出现 >2 次就假。
- 改法：拆成对仗，改成叙述或带主语的口语。
- **边界**：拆的是「连发」，单处对仗允许（≤2）。

### 02 01–06 整齐排比 打散成叙述
AI 爱用 "第一…第二…第三…" 或六条等长的排比。
- 改法：打散成叙事段落，三条字数必须不一样，长短交错。
- **边界（重要）**：打散的是「等长」，**不是「短句」**。禁止把排比统一改成 25–45 字的中等句——这是平稿最大来源。改后必须长短交错，并保留 ≥1 个 ≤12 字极短句独立成段。

### 03 每节都要金句 → 金句 ≤2 且不相邻、不得在结尾
AI 每节塞一句金句，满篇都是「金句」就不值钱。
- 改法：其余降级为普通结论。
- **边界（重要）**：旧版「全文只留 1 句」把高点削平了。改为 **≤2 句、不相邻、不许放结尾**；其余结论句降级但**不许磨平语气**。结尾留口子，见 `zhangli.md` 指标 5。

### 04 「✗错误 / ✓正确」对称模板 + 清单体
AI 最爱把每个分点写成等长的「错误姿势 / 正确姿势」对仗卡，或 5 条一律编号、一律三行。整齐到假。
- 改法：坑与坑之间长度悬殊——有的细写带过程，有的两三句带过；用叙述串联，不套表格模板；编号可保留但内容必须长短交错、有轻重。

### 05 空泛升华 + 数据无语境
AI 爱用「问题不在 A，在 B」「归根结底」「说到底」式抽象收尾替代具体因果；也爱甩孤立数字（只给 45% 不给分布 / 条件 / 谁说的）。
- 改法：用具体机制代替升华——讲清因果链，不给"人生道理"；每个数字附来源 + 语境。
- **边界（重要）**：禁的是**「讲人生道理」**，不禁「当场情绪」「没想明白」「我也说不清」。这些是人味，删了就平。

## 通用 AI tells 速查（通读时逐条过）
- 过多过渡词：说实话 / 其实 / 说到底 / 归根结底 / 值得注意的是
- 完美平衡三段式：三个分点字数一致、结构一致
- 每个分节都喊金句，满篇高亮
- 用"第一/第二/第三"规整排比
- 数据裸奔无语境（只给数字，不给分布、条件、出处）
- 通篇无主语的泛化说教（"人们""我们"堆砌，无"我"的具体痕迹）
- 标题党式对称标题（"不是 X，是 Y"刷屏）

## ⚠️ 反向误删清单（去味时最容易犯的错）

把下面这些当 AI 腔删掉，稿子立刻变平。**这些必须保留**：

| 别删 | 为什么 |
|---|---|
| ≤12 字极短句独立成段 | 节奏落点，不是排比 |
| 不完整句 / 话说一半 / 破折号后收住 | 口语顿挫 |
| 「我也说不清」「后来才知道没那么简单」 | 自我修正 = 落差起点 |
| 具体物件、原话、动作、当场时间点 | 「我」的痕迹，深度三件套的载体 |
| 不解释的情绪 | 人味；解释成道理才是 AI 腔 |
| 一段突然写满 120+ 字、旁边一段只有一句 | 密度差，不是失衡 |

## 改写示范
- 假：「成功不是偶然，是每一个不起眼的坚持堆出来的。」
- 真：「我连续三个月每天写，直到第 92 天才有第一篇破千的阅读。坚持这件事，前 90 天根本看不出意义。」
- 区别：有具体数字、有主语、有过程，不是排比金句。
- **再看节奏**：后面必须跟一个短句落点或一句不解释的话，否则整段又滑回中等长度叙述。示例见 `zhangli.md` 第五节。

## 自检清单（A 组：减法；B 组：加法，两组都要过）

**A 组 · 去味（不许有）**
- [ ] 对仗句 ≤2 处
- [ ] 无等长排比（三条字数不同）
- [ ] 金句 ≤2 句、不相邻、不在结尾
- [ ] 无「✗错误/✓正确」对称模板、无整齐清单体
- [ ] 无空泛升华（用具体因果代替"问题不在X在Y"）
- [ ] 每个数据有来源 + 语境（分布 / 条件）
- [ ] 含机制(为什么) + 案例(过程) + 可落地步骤（深度三件套）
- [ ] 朱雀分数 ≤20/100（不可用朱雀时，本清单为兜底硬门槛）

**B 组 · 张力（必须有，详见 `zhangli.md`）**
- [ ] 落差 ≥1 处（预期 → 带证据的推翻 → 重建）
- [ ] 相邻 4 句字数不全接近；每 300 字 ≥1 个 ≤12 字极短句独立成段
- [ ] 1 个核心场景写透（≥4 个具体项、≥120 字），其余段掠过
- [ ] 开头 3 行是钩子伤口，不是介绍 / 铺垫 / 讲道理
- [ ] 结尾是未闭合的口子，不是总结 / 升华 / 引导关注
- [ ] 平稿检测命中 ≤1 条
- [ ] 有具体时间 / 数字 / 物件 / 原话等「我」的痕迹

> A 组全过、B 组挂了 → **仍然打回**。「干净但平」不算合格稿。
