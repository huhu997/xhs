# 张力与节奏（去味 ≠ 削平）

> 2026-11-11 用户反馈「很平很平」后补的第七份规范。
> 一句话：**去味解决"像不像人写的"，张力解决"人愿不愿意往下读"。两道门槛并列，缺一不可。**

## 零、为什么必须补这一层

复盘旧规范的四个结构性缺陷：

| 缺陷 | 出处 | 后果 |
|---|---|---|
| 五条去味机制全是减法（拆 / 打散 / 降级 / 删 / 代替） | `ai-taste.md` | 所有句子被磨成同一长度、同一语气 |
| 自检清单 9 条全是"不许有 X"，零条"必须有 Y" | 同上 | 无人对"起伏"负责，合格稿也可以是平稿 |
| 写稿骨架是单向因果（现象→外因→内因→定性→框架） | `SKILL.md` 第 3 步 | 读者第 1 段就猜到结尾 |
| 金句全文仅 1 句 + 禁升华 | 机制 03 / 全流程 | 全文只有一个高点，其余全降级 |

结果：信息完整、逻辑通顺、AI 味合格，**但没有一处意外、一处停顿、一处密度落差**。这就是"平"。
历史误判：**去味时把"人味"当"AI 腔"一起删了**，是平稿的直接来源。

## 一、AI 腔 vs 人味（划清边界，不许混删）

| AI 腔 · 必须删 | 人味 · 必须留或加 |
|---|---|
| 对仗连发、等长排比、总分总 | 口语顿挫、话说一半、突然收住 |
| 「归根结底」「说到底」「问题不在 A 在 B」 | 当场情绪，且不解释它 |
| 每段都金句、满篇高亮 | 自我拆台（"我也说不清这算不算…"） |
| 无主语泛化说教（人们 / 我们） | 具体物件、原话、动作、时间点 |
| 五条一律编号、一律三行 | 极短句独立成段（≤12 字） |
| 数据裸奔 | 具体到难看的数字（"三张卡去过十一次"） |

**去味时删左列，不动右列。** 右列被删，稿子立刻变平。

## 二、五条硬指标（写稿必过，逐条可数）

### 1. 落差 ≥1 处
结构：**预期句 → 推翻句（必须带具体证据）→ 重建句**。
禁止全文顺同一个判断一路走到尾。推翻句里不许出现"后来我才发现"就完事，必须跟着一个能核实的事实或数字。

### 2. 长短交错
- 相邻 4 句字数差都 <8 字 → **违规**。
- 每 300 字至少 1 个 **≤12 字的极短句独立成段**。
- 允许不完整句、单句成段、破折号后突然收住、反问不加答案。
- 禁止全篇都是 25–45 字的中等句（这是旧规范最常产出的形态）。

### 3. 密度差（平均用力 = 平）
指定 **1 个核心场景写透**：时间 / 地点 / 动作 / 物件 / 当时一句原话，至少占 4 项，篇幅 ≥120 字。
其余内容一律掠过，段落 ≤60 字、不铺细节。
判断法：全文最慢的一段与最快的一段，字数差 ≥3 倍。

### 4. 开头 3 行 = 钩子伤口
必须是一个**具体的不适 / 失败 / 反常 / 当场画面**。
禁止：自我介绍开场、背景铺垫、"最近很多人问我"、先讲道理、先给定义。
（"我是薄肌小王"这类署名放封面 / 落款，不占正文开头。）

### 5. 结尾留口子
不总结、不升华、不喊口号、不"关注我"、不引导互动式鸡汤。
给一个**未闭合的口子**：还不知道的事 / 还没解决的问题 / 明天要试的那个具体动作。
金句可以有，但**金句不许放在结尾**。

## 三、平稿检测（团长 + S2 共用；命中 ≥2 条即打回重写）

- [ ] 连续 4 句以上字数接近（相邻差 <8 字）
- [ ] 全文无一处推翻 / 自我修正
- [ ] 每段都在「解释」，没有一段在「发生」（无场景、无动作、无对话）
- [ ] 全文无具体物件，只有抽象名词
- [ ] 开头是介绍 / 铺垫
- [ ] 结尾是总结 / 升华 / 引导关注
- [ ] 语气从头到尾一致，无一处突然加速或收住

命中 0–1 条：可放行。命中 ≥2 条：**打回，不是润色能救的**。

## 四、与去味机制的边界（防互相打架，本节优先级最高）

| 原机制 | 旧执行（导致平） | 修正后 |
|---|---|---|
| 02 打散排比 | 统一改成中等长度叙述 | 打散的是「等长」，不是「短句」；改后必须长短交错 |
| 03 金句仅 1 句 | 全文只留一个高点 | **金句 ≤2 且不相邻、不得在结尾**；其余结论降级但不磨平语气 |
| 05 禁空泛升华 | 连当场情绪一起删 | 禁的是「讲人生道理」，不禁「没想明白」「说不清」 |
| 01 拆对仗 | 见对仗就拆 | 拆连发；单处对仗允许（≤2） |
| 04 禁清单体 | 一律不许编号 | 编号可留，但内容必须长短悬殊、有轻重 |

**原则：去味只削"整齐"，不削"起伏"。** 两条规范冲突时，以本节为准。

## 五、改写示范（本轮真实稿件，同一段）

**平版（原稿）**
> 说出来你可能不信：我有件事坚持了三年，每周四次，一次四十分钟，从没请过私教，也没天天称克数吃饭。但我从不觉得自己在"坚持"。
> 是练薄肌。
> 反观我其他那些"这次一定要好好搞"的事——年初列计划、冲动下单的课、凌晨发誓要改变——没一个活过两个月。每次开头都猛，第二周就悄无声息了。

**起伏版**
> 第三次把健身卡塞进抽屉的时候，我算了笔账：两年，办了三张，一共去过十一次。
> 但练薄肌这事，我做了三年，一次没断。
> 没请私教。不称克数。每周四个晚上，四十分钟，练完洗澡睡觉。
> 我也说不清这算不算自律。
> 因为我一次都没「坚持」过。
> 同一段时间里，我买过七门课，列过四份年度计划。最长那份活了十九天。

差别：具体数字、极短句独立成段、当场动作（塞进抽屉）、自我拆台（"我也说不清"）、落差（"没坚持过"却"没断"）、不解释、不总结。

## 六、张力三问（团长写稿前必答，写进制作包）

1. 读者读到第 3 行会以为这篇要讲什么？我在**哪一段**推翻它？
2. 全文最「慢」的一段是哪段（写透的场景）？最「快」的一段是哪段（一句带过）？
3. 结尾最后一句，是总结还是口子？

三问答不上来 → 不许开写。

## 七、交接（各角色增量）

| 角色 | 增量动作 |
|---|---|
| S1 选题侦察兵 | 选题包加「**张力锚点**」：1 个反常识事实 或 1 个具体场景（带来源 / 可核实） |
| 团长 | 写稿前过张力三问；成稿过五条硬指标；制作包记录三问答案 |
| S2 去味编辑 | 去味后跑**平稿检测**；命中 ≥2 打回。允许补极短句 / 拆长段 / 调段落顺序制造落差，**仍不许改观点** |
| 团长回报 | 增加「张力结论：平稿检测命中 N 条，通过 / 打回」 |

> 与 `ai-taste.md` 并列为**双门槛**：朱雀 ≤20/100 管"像不像人"，平稿检测 ≤1 条管"想不想读"。任一不过都不得进 S3/S6。

## 八、数字不挪用（2026-11-12 用户纠偏）

> 触发：第 1 集标题《26 秒的片子两小时做完，我却磨了三年》。事实是「两小时 = 做片子」「三年 = 练薄肌」，两件事。标题把三年安到做片子上做反差，是**失真**，不是修辞。用户原话：「没有磨三年 有点夸张了 不能这么说」。

**硬规矩（写稿 + S2 终检共用）**

1. **反差只能用同一件事上的真实数字**。A 事的时长 / 数量 / 次数，不许安到 B 事上，哪怕读起来更有张力。
2. 禁止「磨了 N 年」「花了 N 年才做出…」「N 年换来…」这类把**长期习惯**算成**项目工期**的写法。习惯时长只写它本身：「薄肌练了三年」「每周四次，四十分钟」。
3. 两组数字并列时，**各自归属必须写清**：「两小时是片子的，三年是薄肌的」。归属不清的并列即视为挪用。
4. 标题里每出现一个数字，问一句：**这件事真的花了这么久 / 这么多吗？** 答不上来就换掉，不许「约等于」。
5. **无素材佐证的当日状态 / 内心活动不许写成事实**（如「那天状态其实很烂」）。机制可写成一般描述（「不需要哪天特别有劲」），不许虚构某个具体日子。
6. 第五节「改写示范」里的健身卡 / 课程 / 年度计划数字**仅作节奏示意，不得照抄进成稿**；成稿数字一律来自可核实素材。

**S2 终检增量**：逐个数标题与正文的数字，列「数字 → 归属事件 → 素材来源」三列；任一格填不出 → 打回。
**团长回报增量**：制作包写明「数字归属核对：通过 / 打回」。

> 张力不够，靠**多一层推翻、多一个具体物件**补，不许靠放大数字补。
