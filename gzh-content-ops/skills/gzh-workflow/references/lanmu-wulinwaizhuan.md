# 栏目模板：A 股江湖每日说书（武林外传·同福客栈群像）

> 用于**栏目化连载**（不是一次性文章）。核心不是排版，是**固定班底 + 连续回目**带来的追更感。
> 适用账号：以 `config/account.md` 的 `account_name` 为准（当前「薄肌小王翻盘实录」）；封面/落款署名取 `cover_byline`，自称取 `pen_name`。本模板为《A股每日复盘》栏目专用，其他栏目可参照改造角色卡。
> 注：下方角色表里的「掌柜·中登小王」是**栏目虚构角色名**（词源设定见 `assets/ip/长盈客栈人物设计探讨.md`），不是账号署名，不随账号改名而改。

## 一、什么时候用

- 用户明确说「复盘」「今日盘面」「老掌柜」「客栈」「武林外传」等
- 或指定 `栏目 = A股江湖每日说书`
- **未指定栏目时不要默认套用**，走通用八段式

## 二、核心规则

- 每期一个**回目**：`第N回 上联，下联`——七/八字对仗，概括当日盘面
  例：`第一回 节前客栈齐收账，退潮江湖各西东`
- 回数**连续累计**，每期各不相同，写进标题前缀
- **固定客栈「长盈客栈」+ 固定班底（每期全出场）**，数据用**对话 + 口头禅**推进，不是单口独白
- 数字必须真实、口径稳定（与通用稿数据要求一致，宁少不编）

## 三、固定班底（角色卡 · 每期沿用）

| 角色 | 身份 | 口头禅 / 功能 | 配色（身份标签） |
|:---|:---|:---|:---|
| 掌柜·中登小王 | 说书人本体 / 定调 + 合规红线 | 「额滴神呀」「咱长盈客栈」 | 朱红 `#B23A2E` |
| 跑堂·小散 | 散户视角 / 追涨杀跌、一惊一乍 | 「掌柜的，我这点碎银…」 | 琥珀 `#C8862A` |
| 账房·老机 | 机构/量能视角 / 拨算盘报数 | 「（拨拉算盘）慌甚慌」「量能又缩了」 | 青蓝 `#2F6E8F` |
| 捕快·证监爷 | 异动/监管 / 巡市面 | 「莫要乱来」「跌停板上有名」 | 靛紫 `#6B4E9E` |
| 算命·道长 | 分析师 / 夜观天象 | 「贫道夜观资金流向」「天象有变」 | 暗金 `#8A7A3C` |
| 画外音 | 旁白 / 片尾点化 + 下回预告 | 「这正是…」「欲知后事如何…」 | 斜体 + 左侧色条 |

> ⚠️ 角色配色只作**身份标签**，不得挪用涨跌色。涨跌色全局统一：**红涨绿跌**。

## 四、标准章节（正传，可按当日增删）

1. **【开场】** 画外音定场（日期/节气）+ 客栈晨会（掌柜定场、小散惊呼、老机报数）→ 当日八字核心
2. **【正传一】大盘**——证监爷报指数表 + 道长点三桩反常
3. **【正传二】昨日观察点对账**——掌柜起头，老机/证监爷/道长分报，小散插话
4. **【正传三】资金去向**——掌柜问、小散答、老机列抱团、证监爷点领跌、道长收口
5. **【正传四】三条暗线 / 传导链**——道长主述
6. **【正传五】辅助线索 n 条**——小散讨闲笔、掌柜速报
7. **【插叙】老掌柜讲古**——两年前的今天 / 特别视角
8. **【正传六】节前心理 / 主线定性**——掌柜起、道长点破
9. **【片尾·点化】** 画外音一句点题 → 掌柜/老机收口 → 节后观察点（量化条件）→ 赞转 → 前情回顾

## 五、外传（非交易日）

- 栏目统称「A股江湖每日说书」：**交易日发正传（复盘回），非交易日发外传（闲篇回）**
- 回数连续、班底不变、世界观共用
- 三类固定栏目：
  1. **【老掌柜讲古】**：历史上的今天、经典战役、政策旧闻、江湖规矩科普——全真实数据，合规安全度最高
  2. **【客栈夜话】**：读者留言答疑、常见误区拆解、黑话科普（PE/PB/杠杆/融券）——只讲框架不荐股
  3. **【道长观星】**：重大事件前「N 种情景框架」，**必带「非预测、是应对框架」免责**
  - 可加 **【书接上文】**：长假中段把前几回收评、主线梳理
- 外传回目同样对仗。例：`第二回 老掌柜开坛说杠杆，碎银借据暗藏刀`

## 六、配色

**客栈暖木**：底 `#F4E8D0` 宣纸米黄 / 主色朱红 `#B23A2E`＝涨 / 青瓷绿 `#3F7A5E`＝跌 / 暗金 `#B8923F`

对应 `themes.md` 第 13 套「国潮」（`#9E1B1B` / `#F3E9D2` / `#C8A24B`）可作近似替代，但以本节色值为准。

## 七、HTML 组件

- `dlg(speaker, text, color)`：对话组件——左侧角色色块标签 + 右侧正文字段，自动 span-leaf 包裹
- `vo(text)`：画外音组件——斜体 + 左侧色条
- 五角色色彩在 HTML 顶部常量定义（`ZHANGGUI / XIAOSAN / LAOJI / YE / DAO`），新增角色同步加常量

参考实现（已收编进包）：`${EXPERT_DIR}/assets/templates/build_preview.py`，路径表见 `${EXPERT_DIR}/config/paths.md`

## 九、合规红线（比通用稿更严）

非交易日更容易「飘」成荐股/预测，铁律不变：

- 不点买卖、不预测点位、不涉政涉外
- 讲古只用真实数据；夜话只讲框架；观星**必加免责**
- 任何「上车/抄底/满仓」类表述一律删

## 十、交接给 S2 的注意事项

去味编辑不要把这个栏目的「群像对话体」当成 AI 味打散——**角色口头禅、对话推进是栏目资产，不是排比**。要打散的是：八股对仗、空泛升华、「首先其次」。判据：删掉这句，人物是否还立得住。
