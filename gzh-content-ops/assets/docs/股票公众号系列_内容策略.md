# 股票公众号 → 私域变现 · 全系列内容策略

## 核心原则

```
不卖"秘籍"，卖"体系"
不承诺收益，展示逻辑
不硬推付费，靠内容钩子
```

三句话原则：让读者觉得"这人真懂"→"他确实能帮到我"→"我想跟他学"

## 第四阶段：私域运营

### 社群定位
- **免费群**：日常资讯、早报、免费问答、每周复盘简版
- **付费群（199-399元/月）**：每日操作策略、盘中提醒、每周深度复盘、持仓分析、一对一答疑

### 付费转化路径
```
公众号积累信任（1-3个月）
    ↓
文章内嵌入免费钩子（"加微信领资料"）
    ↓
免费群运营（1周-1个月，持续输出价值）
    ↓
付费群转化（限量名额，先到先得，制造稀缺）
    ↓
续费靠实打实的收益率（长期运营）
```

### 定价建议
- **起步期**：免费群养3个月以上再推付费
- **付费群首期**：99元/月试水，限制30人
- **跑通后**：逐步提价到299-399元/月
- **高端服务**：1对1持仓诊断（999元/次）

## 关键成功要素

1. **频率**：每周2-3篇，稳定输出，不要断更
2. **真实**：对错都说，别只报喜不报忧 — 真实感是最好的信任建设
3. **互动**：评论区认真回复，每条回复都是信任积累
4. **渐进**：不要在前10篇提任何付费，忍住
5. **差异**：不做"明天涨停"那种号，做"体系化交易"的定位 — 粉丝质量高，付费意愿强
