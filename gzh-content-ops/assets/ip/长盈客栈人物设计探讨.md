## 1. 项目背景
- **产品**：「长盈客栈」IP 下的竖屏多格条漫（连环画），每日"演"当天行情。
- **内容定位**：A股/美股**光模块 · AI算力主线**投研内容的轻量化表达（主线掘金、理性不追涨、看数据）。
- **目标人群**：炒股散户——既要"韭菜共鸣"（笑点），又要"理性引导"（不追涨、看数据）。
- **两条内容线（并列）**：
  - 说书线（已有）：文字深度复盘，主理人第一视角。
  - 连环画线（新）：固定班底演行情，滑屏吸粉。
- **商业路径**：条漫吸粉 → 导流社群/订阅。合规红线：**只输出观点，绝不涉及具体买卖操作**。
- **IP 连贯**：两线共用「长盈客栈」世界观与客栈暖木配色。

## 4. 已验证的锁角经验（直接影响设计取舍）
1. **掌柜总被画老**：设定三十余岁，生图常成四十~五六十。锚点"茶盏+眼镜"偏弱，模型易向"老掌柜"漂移。
2. **老机胡须失控**："三缕长须"被画成夸张长须/络腮，合照抢戏。
3. **三人合照漂移**：同框时特征互相干扰；**单人 ref 比合照稳定得多**（故已改为先锁单人 ref）。
4. **围裙易丢**：掌柜靛蓝围裙、小散围裙生图常漏画。
5. **结论**：每个角色需 1~2 个"焊死"的强锚点（形状/配色/独特道具），不能只靠"年龄+神态"软描述。

## 5. 人物设计核心议题（已提出，未定稿，待续聊）
### 5.1 功能定位（骨架评估）
三角色功能互补（权威 + 共鸣 + 数据），**骨架没问题**，不需推翻，往细里打磨即可。

### 5.2 名字与身份隐喻是否升级
- 「中登小王」：中登=中国证券登记结算，圈内梗正；但"小王"偏亲切、弱了权威 → 可保留原名，视觉上强化"掌柜权威感"。
- 「老机」：江湖气重，"账房+算盘"偏古 → 是否往"量化老炮 / AI模型训练师"贴（道具算盘→古风终端），更贴光模块/AI算力主线？
- 「小散」：直白、共鸣强，建议保留。

### 5.3 每人一个"金融人格图腾"（设计层，也顺手解决锁角）
- 掌柜 → **定海神针**：静态物（茶盏/罗盘），隐喻"掌方向、不慌"。
- 小散 → **追涨杀跌体**：可设计成"手里东西随行情变"（涨举红旗、跌抱头）或"红绿两副表情"——比呆毛更叙事。
- 老机 → **冷数据**：永远在算的物（算盘/竹简屏）+ 冷脸。

### 5.4 是否缺"对手戏"角色（戏剧冲突源）
当前三人皆"自己人"，无观点碰撞。可加：
- 「唱空居士 / 空仓道人」（永远看空，制造观点碰撞）
- 或「游资大头」（拉抬主力，小散的对立面）
加人 = ref 多一张 + 成本升，但剧情更活。**待定：加 or 不加。**

### 5.5 小散"成长弧"
日更若每期小散都"又惊了"会腻。可设计**偶尔学乖一次**的反差（某期没追高被掌柜夸），给读者"跟着学"的代入感。

## 6. 关键新提案：中登小王代入「用户真人 IP」
用户提出：掌柜"中登小王"直接代入**用户本人真实形象**。
- **可行性**：技术上即已验证的图生图 ref 机制——用户照片当 `image1`，脸锁死成本人，跨格一致；**顺便彻底解决 §4-1 掌柜显老痛点**。
- **利弊**：
  - 利：强人设/强信任（财经真人主理人转化高）；与说书线人格天然统一；形象固化反而加分（"中登小王"本就是用户公开署名）。
  - 弊：形象固化后难改；真人特征（脸型/发型/胖瘦）焊进 IP。
- **落地**：用户给清晰正面照 → 当掌柜 ref → 图生图，脸锁本人，服饰按提示词换"藏青长衫+靛蓝围裙+茶盏+发髻"。
- **待定（A/B）**：
  - **A 保留古风壳**：脸是你、穿藏青长衫梳发髻拿茶盏（画风统一，"古人脸是你"反差有记忆点）——**当前倾向 A**。
  - **B 半现代**：脸是你、换盘扣立领主理人衫+围裙（更像真人主理人出镜，弱化古装）。
- **照片要求**：正面、光线均匀、背景干净、无遮挡、不戴帽；戴镜与否需与"圆框眼镜掌柜"一致。
- **保真度**：真人照转插画 `input_fidelity` 约 0.6~0.7（脸仍像你、服饰自然融合）。
