# 公众号文章创作工作流（自动生图版）

一站式公众号文章创作 + 自动配图。适用场景：财经分析、热点解读、行业深度、产品测评等。

---

## 一、前置准备

### 1.1 安装 bun（一次性）

```bash
npm install -g bun
```

### 1.2 首次登录 Gemini（一次性）

Gemini 生图依赖 Cookie。**只需首次登录一次，后续不再需要浏览器。**

```bash
# 1. 启动带调试端口的 Opera（仅首次登录需要）
"F:/Programs 应用程序/O浏览器/opera.exe" \
  --remote-debugging-port=9222 \
  --user-data-dir="F:/桌面/zcode工作区/.gemini-opera-profile"
```

浏览器打开后，访问 https://gemini.google.com 完成一次 Google 登录。

```bash
# 2. 执行登录，提取 Cookie 并缓存到文件（只需执行一次）
bun "F:/桌面/Gemini本地文件/Github/github下载工具/tools_workspace/article-tools/server/gemini-gen.mjs" --login
```

**完成后即可关闭 Opera！** 后续生图直接从缓存文件读取 Cookie，不再需要打开浏览器。

> 💡 **原理**：脚本从 Opera CDP 获取登录 Cookie → 缓存到磁盘文件 → 自动轮换 `__Secure-1PSIDTS`（防止过期）。后续所有生图调用直接从缓存读取，浏览器可关。

## 二、工作流步骤

### Step 1 — 联网调研

用 WebSearch 搜索与主题相关的**最新信息**。财经类优先搜索本周/本月数据。

**搜索技巧：**
- 中英文关键词各搜一轮（如 "SK海力士 美股上市" + "SK Hynix Nasdaq IPO"）
- 搜索"股价大跌/大涨"时要带日期范围
- 搜索机构观点、后市展望、关键时间节点

**输出：** 整理数据表格 + 关键时间线 + 核心逻辑链

### Step 2 — 设计配图方案（4张）

根据文章内容设计 4 张配图：

| 图片 | 用途 | 比例 | 内容方向 |
|------|------|------|----------|
| **封面图** | 文章顶部，杂志风格 | **2.35:1**（兼容 1:1 裁剪） | 主旨视觉化，品牌感 |
| **配图1** | 核心数据/关键信息 | 16:9 | 对比、图表、数据可视化 |
| **配图2** | 概念拆解/原因分析 | 16:9 | 逻辑框架、产业链、因果链 |
| **配图3** | 总结/展望/对比 | 16:9 | 十字路口、未来方向、风险提示 |

> **封面图双比例设计要点：**
> - 微信会同时展示 **2.35:1**（订阅号列表）和 **1:1**（朋友圈分享）
> - 以 2.35:1 为画布，所有关键内容（标题文字、核心主题）集中在**中间 42% 宽度**的安全区内
> - 安全区外（左右两侧）只放背景装饰元素，不放文字和重要主体
> - 按 2.35:1 构图 → 微信自动裁切到 1:1 时，中间内容不被切割

### Step 3 — 自动生成图片

使用 `gemini-gen.mjs`（基于 baoyu-danger-gemini-web 逆向工程核心机制），从缓存 Cookie 直接调 Gemini API 生成图片，**无需打开浏览器**。

> **备选通道（自 2026-09-24 起，推荐优先）：WorkBuddy 内置 ImageGen**
> - 不依赖 Opera/Gemini Cookie，直接调内置出图（`ImageGen` 工具，单张约 5–10 信用分）。
> - **扩散模型中文/数字渲染不可靠** → 图只做**纯场景插画/氛围图，不嵌数字**；数字全部留在 HTML 正文里。
> - 参数：`size="1536x1024"`（横版）、`quality="high"`、`output_dir=<文章slug目录>`；出图后重命名为 `cover.png/gushi.png/lever.png` 以便 `<img src="...">` 引用。
> - `build_preview.py` 里用 `img(name, caption)` 组件内嵌（校验器放行 `<img>`；勿加 class/id）。
> - ⚠️ 图角带平台水印「AI生成 / WorkBuddy」，正式发布前需处理（裁切 / 覆盖 / 去水印工具）。

#### 3.1 环境变量

```bash
# 不需要手动设代理！脚本会自动检测/启动 Linsoc
# 如需覆盖，可显式指定：
# export HTTPS_PROXY=http://127.0.0.1:1080
```

#### 3.2 变量定义

```bash
GEMINI_SCRIPT="F:/桌面/Gemini本地文件/Github/github下载工具/tools_workspace/article-tools/server/gemini-gen.mjs"
IMG_DIR="F:/桌面/zcode工作区/<文章英文slug>"
mkdir -p "$IMG_DIR"
```

#### 3.3 逐张生图（顺序执行）

```bash
# 封面图（2.35:1，兼容1:1裁剪 — 主体放中间）
bun "$GEMINI_SCRIPT" -p "Clean Swiss editorial 3D style, [画面描述]. Chinese labels: '[标签]'. 2.35:1 aspect ratio, safe for 1:1 center crop — keep main subject centered in middle 42%." -i "$IMG_DIR/cover.png"

# 配图1 - 数据/对比（16:9）
bun "$GEMINI_SCRIPT" -p "配图1 prompt..., 16:9 aspect ratio" -i "$IMG_DIR/data.png"

# 配图2 - 概念/原因（16:9）
bun "$GEMINI_SCRIPT" -p "配图2 prompt..., 16:9 aspect ratio" -i "$IMG_DIR/chain.png"

# 配图3 - 展望/总结（16:9）
bun "$GEMINI_SCRIPT" -p "配图3 prompt..., 16:9 aspect ratio" -i "$IMG_DIR/outlook.png"
```

#### 3.4 批量生图（可选）

可以将所有 prompt 写在文件里，批量生成：

```bash
# batch.txt 格式：每行一个 prompt
echo "封面图prompt..." > "$IMG_DIR/prompts.txt"
echo "配图1 prompt..." >> "$IMG_DIR/prompts.txt"

# 逐行读取执行
while IFS= read -r p; do
  name="${p:0:10}"  # 取前10个字作文件名
  bun "$GEMINI_SCRIPT" -p "$p" -i "$IMG_DIR/${name}.png"
done < "$IMG_DIR/prompts.txt"
```

#### 3.5 其他常用命令

```bash
# 查看 Cookie 缓存状态
bun "$GEMINI_SCRIPT" --status

# 手动轮换 Cookie（通常不需要，脚本会自动处理）
bun "$GEMINI_SCRIPT" --rotate

# 重新登录（Cookie 完全失效时）
# 先启动 Opera → 登录 Gemini → 然后：
bun "$GEMINI_SCRIPT" --login
# 完成后可关掉 Opera
```

每张图生成后用 `Read` 工具确认文件存在。某张报错 → 脚本会自动尝试轮换 Cookie 后重试，一般不需要手动干预。

### Step 4 — 撰写文章

**公众号风格规范：**

| 要素 | 要求 |
|------|------|
| **标题** | 有冲击力，带数字或问句，15-25字 |
| **导语** | 1-2句提炼核心，引用块样式 |
| **正文** | 短段落（手机阅读友好），每段不超过5行 |
| **小标题** | 醒目，带emoji，彩色左边框 |
| **数据展示** | 用表格，带表头颜色 |
| **风格** | 通俗易懂，有观点有态度 |
| **章节数** | 5-7章 + 插曲（可选）+ 结语 |

**常用章节结构：**
1. 事件概述/历史性时刻
2. 反常现象/矛盾点
3. 原因拆解（多重因素）
4. 系统背景/更大图景
5. **插曲**：前一天的铺垫（可选）
6. 深入分析/信仰考验
7. 后市展望 + 下周关键时间节点
8. 结语：深度反思

### Step 4b — 武林外传·同福客栈群像框架（A股每日复盘专用，自 2026-09-24 起）

> 中登小王AI长盈记《A股每日复盘》从 2026-09-24 起改为「武林外传式客栈群像」版（满配群像）。本框架为其专属，覆盖通用 Step 4。
> 参考蓝本：武林外传（同福客栈）——固定班底 + 各自口头禅 + 对话推进剧情 + 跑题讲古 + 片尾点化 + 下回预告。

**核心规则**
- 每期一个**回目**：`第N回 上联，下联`——七/八字对仗，概括当日盘面。例：`第一回 节前客栈齐收账，退潮江湖各西东`。
- 回数**连续累计**（第一回、第二回…），每期回目各不相同。
- **固定客栈「长盈客栈」+ 固定班底（每期全出场，读者追更）**，数据用**对话 + 口头禅**推进，不是单口独白。
- **数字必须真实、口径不变**（与通用 Step 4 数据要求一致）。

**固定班底（角色卡 · 每期沿用）**
| 角色 | 身份 | 口头禅 / 功能 | 配色（身份标签，非涨跌色） |
|:---|:---|:---|:---|
| 掌柜·中登小王 | 说书人本体 / 定调 + 合规红线 | 「额滴神呀」「咱长盈客栈」 | 墨绿 #2E6B4F |
| 跑堂·小散 | 散户视角 / 追涨杀跌、一惊一乍 | 「掌柜的，我这点碎银…」 | 琥珀 #C8862A |
| 账房·老机 | 机构/量能视角 / 拨算盘报数 | 「（拨拉算盘）慌甚慌」「量能又缩了」 | 青蓝 #2F6E8F |
| 捕快·证监爷 | 异动/监管 / 巡市面 | 「莫要乱来」「跌停板上有名」 | 靛紫 #6B4E9E |
| 算命·道长 | 分析师 / 夜观天象 | 「贫道夜观资金流向」「天象有变」 | 道袍金 #8A7A3C |
| 画外音 | 旁白 / 片尾点化 + 下回预告 | 「这正是…」「欲知后事如何…」 | 斜体 #EDE8DC 底 |

**标准章节（可按当日增删）**
1. 【开场】画外音定场（日期/节气）+ 客栈晨会（掌柜定场、小散惊呼、老机报数）→ 当日八字核心
2. 【正传一】大盘（证监爷报指数表 + 道长点三桩反常）
3. 【正传二】昨日观察点对账（掌柜起头，老机/证监爷/道长分报，小散插话）
4. 【正传三】资金去向（掌柜问、小散答、老机列抱团、证监爷点领跌、道长收口）
5. 【正传四】三条暗线 / 传导链（道长主述）
6. 【正传五】辅助线索 n 条（小散讨闲笔、掌柜速报）
7. 【插叙】老掌柜讲古（两年前的今天 / 特别视角，掌柜主述，老机对比）
8. 【正传六】节前心理 / 主线定性（掌柜起、道长点破）
9. 【片尾·点化】画外音一句点题 → 掌柜/老机收口 → 节后观察点（量化条件）→ 赞转 → 前情回顾

**HTML 实现要点**（见 `articles/20260924-daily-recap/build_preview.py`）
- 对话组件 `dlg(speaker, text, color)`：左侧角色色块标签 + 右侧正文字段，自动 span-leaf 包裹。
- 画外音组件 `vo(text)`：斜体 + 左侧色条。
- 五角色色彩在 HTML 顶部常量定义（ZHANGGUI/XIAOSAN/LAOJI/YE/DAO），新增角色时同步加常量。

**配图（正传 9 张）**：cover（回目题图）/ data / verify / money / chain / clues / ebb / outlook / share。（**外传回精简为 3 张**：cover / gushi / lever）
**出图通道**：优先 WorkBuddy 内置 ImageGen（见 Step 3 备选通道）；**纯场景插画、不嵌数字**，数字留正文。
**配色（自 2026-09-24 起）**：**客栈暖木** —— 底 `#F4E8D0` 宣纸米黄 / 主色朱红 `#B23A2E`＝涨 / 青瓷绿 `#3F7A5E`＝跌 / 暗金 `#B8923F`；**红涨绿跌（标准）**。角色配色（掌柜朱红/小散琥珀/老机青蓝/证监爷靛紫/道长暗金）仅作身份标签，不挪用涨跌色。
**合规不变**：不点买卖、不预测、不涉政涉外。

**外传·非交易日延续规则（自 2026-09-25 起）**
- 栏目统称「A股江湖每日说书」：**交易日发正传（复盘回），非交易日发外传（闲篇回）**；回数连续累计、班底不变、世界观共用。
- 外传三类固定栏目（满配群像照常出场）：
  1. **【老掌柜讲古】**（映射老白吹牛/老邢讲案）：A股历史上的今天、经典战役、政策旧闻、江湖规矩科普——全真实数据，合规安全度最高。
  2. **【客栈夜话】**（映射众人围坐闲聊）：读者留言答疑、常见误区拆解、黑话科普（PE/PB/杠杆/融券）——只讲框架不荐股。
  3. **【道长观星】**（映射算命道长夜观天象）：重大事件前「N种情景框架」，必带「非预测、是应对框架」免责。
  - 另可加 **【书接上文】**：长假中段把前几回收评、主线梳理。
- 外传回目同样 `第N回 上联，下联`，题材不同但须对仗。例：`第二回 老掌柜开坛说杠杆，碎银借据暗藏刀`。
- 外传回**配图精简为 4 张**：cover（回目题图）/ gushi（讲古意境）/ lever（机制示意）/ share（赞转）。
- 非交易日更易「飘」成荐股/预测，铁律不变：不点买卖、不预测、不涉政涉外；讲古用真实数据、夜话只讲框架、观星必加免责。

## 四、常见注意事项

| 场景 | 处理方式 |
|------|----------|
| **首次使用** | 启动 Opera（带 `--remote-debugging-port=9222`），登录 Gemini，执行 `--login` 缓存 Cookie |
| **Cookie 过期/报 auth 错** | 脚本会自动轮换 `__Secure-1PSIDTS`，一般无需手动处理。若持续失败，重跑 `--login` |
| **Opera 重启后需要补什么吗** | **什么都不用补**。脚本直接连 `127.0.0.1:9222` HTTP 端点拿 WebSocket URL，绕过 DevToolsActivePort |
| **图片颜色方向** | **A股内容**：红涨绿跌；**美股内容**：绿涨红跌 |
| **生成图片不满意** | 修改 prompt 重新生成同一文件名覆盖 |
| **封面图比例** | 用 2.35:1 生成，主体放中间 42% 安全区。微信会自动裁出 1:1 用于朋友圈分享，中间内容不被切 |
| **网络问题** | 脚本会自动检测/启动 Linsoc（端口1080）。如需切换节点，在系统托盘 Linsoc 图标选择"新加坡代理1" |
| **脚本找不到** | 检查 `GEMINI_SCRIPT` 路径是否正确，或直接用绝对路径 |
